# 从零到出片学习路径

**摘要**：建议按五个阶段学习：① 概念与器材连接；② 安全架设、平衡与极轴校准；③ 构图、对焦、跟踪与导星；④ 亮场、校准帧和数据记录；⑤ 叠加与基础后期。每一步都用短测试序列验收，OSC、单色、单反/无反或智能设备可按已有器材和目标选择，不设唯一入门路线。

## 背景 / 适用场景
适合已完成器材选购、能在至少一个晴夜连续操作 2–4 小时的环境。建议先在白天/傍晚完成粗对焦、线缆连接、设备平衡等准备，夜间只做精调与拍摄，避免手忙脚乱。

## 核心知识点
- 阶段一·概念与准备：理解赤道仪跟踪原理、天体坐标（赤经/赤纬）、极轴含义、焦距/像素对应的视场与采样；白天练习器材组装、线缆规划、粗对焦、平衡。
- 阶段二·架设与极轴校准：稳固三脚架、装上真实载荷并完成平衡，再用极轴镜、电子极轴或漂移法校准。可接受误差取决于焦距、采样、目标位置、曝光和总时长；以正式配置的连续主相机测试帧验收，不套用固定角分门槛。
- 阶段三·对焦与导星：用巴式遮光罩（Bahtinov Mask）或电调焦+EAF 做精确对焦（看最细星点）；用导星镜或 OAG 配合 PHD2/ASIAIR 导星。以主相机测试帧的星点圆度/FWHM、成像采样和 PHD2 日志共同判断是否达标，不把固定 RMS 当作通用门槛；确认后再拍亮场。
- 阶段四·拍摄与校准帧：先制冷并固定相机设置，拍亮场时记录曝光、温度、增益、偏置/读出模式等状态。Dark 匹配 Light；Dark Flat 匹配 Flat；Bias 匹配相机读出状态；Flat 保持同一光路/滤镜且未饱和。单张曝光以试拍得到的天空背景、目标亮度、相机动态范围和跟踪表现决定，累计有效曝光通常比套用固定秒数更重要。
- 阶段五·叠加与后期：用校准帧先校正亮场（暗场减暗电流、平场校正渐晕与灰尘、偏置去读出噪声），再星点对齐叠加（软件如 PixInsight、Siril、深空盒子内置流程、Registar）；叠加后做拉伸（ScreenTransferFunction/直方图拉伸）、降噪、色彩与对比调整出片。
- 推荐软件栈：采集控制 ASIAIR / N.I.N.A / APT；导星 PHD2；叠加与后期 PixInsight / Siril（免费）/ AstroPixelProcessor。
- 学习节奏：先出‘第一张干净不拖线的单目标’（如 M42、M31），再追求总曝光时长与窄带多通道；不要一上来就挑战小星系或单色窄带。

## 注意事项
- 设备重新架设、移动、碰撞或发生下沉后，应复核极轴；固定台也应按运行记录定期验证。星点异常时同时检查极轴、风、平衡、线缆、机械和导星。
- 校准帧不使用一条“全都匹配亮场”的规则：Dark 匹配 Light；Dark Flat 匹配 Flat；Bias 匹配相机读出状态而非 Light 曝光；Flat 需保持同一光路/滤镜并处于线性、未饱和区。制冷相机应提前稳定到可复现的温度。
- 不要省略平场：镜头/传感器的灰尘与渐晕会让画面出现暗角与脏点，后期难补。
- 主相机测试帧出现拖尾或 PHD2 曲线异常时，先查极轴、平衡、线缆牵绊、风和导星星选择，而非只盯一个 RMS 数字或盲目加曝光。
- 月光与光害的影响取决于月亮和目标的角距/高度、目标光谱、滤镜、透明度与构图；先用规划软件和试拍背景判断，不按月相名称机械分配目标。
- 单反/无反的传感器温度不易固定，建立暗场库时要特别注意温度与读出设置匹配；是否升级制冷相机应由项目需求、实测噪声和预算决定。
- 原始亮场常显得灰暗，叠加与拉伸是工作流的重要部分；处理强度应服务于信噪比、色彩和项目用途，不用固定百分比描述前后期贡献。

## 示例
- 首夜实操顺序示例：架三脚架+赤道仪 → 粗对极轴 → 装镜与相机、接线 → 开机制冷至可稳定复现的温度 → 软件精对极轴 → 巴式罩粗/精对焦 → 接导星、PHD2 校准并检查主相机测试帧与日志 → 用少量测试帧确定曝光/增益 → 开始正式序列 → 在不改变光路时补拍所需校准帧。
- 新手友好目标：M42 猎户座大星云（冬季明亮、易构图）、M31 仙女座星系（秋季大视场）、M45 昴星团（广域）。
- 示例参数（APO 250–500mm + OSC 制冷相机）：选择相机可稳定复现的温度和经试拍确认的增益/单张曝光；优先累积足够的有效时长，并以主相机星点与背景直方图复核设置。
