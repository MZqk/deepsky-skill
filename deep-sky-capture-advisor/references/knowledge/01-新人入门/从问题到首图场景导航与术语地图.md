# 从问题到首图场景导航与术语地图

**摘要**：不要按“我应该先看完所有教程”开始。先选你眼前的问题：已有设备、今晚首拍、已有原始数据或拍摄失败；完成对应页面的最小验收后再进入下一步。首图的目标是获得一组可解释、可复处理的原始数据和一张基础成图，而不是第一次就追求复杂设备或满分成片。

## 先选你的入口

| 你现在最像哪种情况 | 先进入 | 这一轮的完成标准 |
|---|---|---|
| 手上已有相机、镜头、智能镜或赤道仪，不知道能否拍深空 | [已有设备如何开始深空摄影](/01-新人入门/已有设备如何开始深空摄影.md) | 写清设备、跟踪方式、可见天空和一个可验证目标。 |
| 还在购买或升级，担心“单件能用、整套不能用” | [购买前成像系统设计与兼容性清单](/01-新人入门/购买前成像系统设计与兼容性清单.md) | 光路、机械、供电、控制和数据链都能逐项核对。 |
| 计划在城市阳台或看不见北极星的地方首拍 | [城市阳台首次深空拍摄](/03-拍摄SOP/城市阳台首次深空拍摄.md) | 完成安全、天空开口、目标和最小测试帧检查。 |
| 已有 Lights 与校准帧，想做第一张基础成图 | [Siril 新手首图工作流](/04-后期处理/Siril新手首图工作流.md) | 留下未覆盖的原始数据、线性主图、处理记录和一张导出图。 |
| 画面已经变差、设备掉线或整晚结果不对 | [单张检查与翻车诊断](/08-FAQ/单张检查与翻车诊断.md) | 先确定是否必须停止，再做一次只改变一个变量的验证。 |

## 首图的四个关口

1. **可运行**：设备能安全供电、不会碰撞、能保存原始文件。白天干跑通过不等于夜间已经验收。
2. **可跟踪与可对焦**：星点在你的焦距、采样、天气和曝光条件下达到可接受状态；不要用别人的固定 RMS 或曝光秒数代替实测。
3. **可解释**：每组数据能说明拍了什么、何时拍、相机状态是什么、用了哪些校准帧。
4. **可复处理**：原始数据不被覆盖，线性主图、处理步骤和导出图都被保留。

某一关没有通过时，不要用更激进的后期跨过它。回到对应的现场、校准或数据页面补齐输入，通常比继续累积问题帧更省时间。

## 最小术语地图

| 术语 | 先这样理解 | 它与下一步的关系 |
|---|---|---|
| 跟踪 | 让设备以合适方式抵消天体的视运动，使连续子帧能用于叠加。 | 决定长曝光是否会拖线；不同设备的实现方式不同。 |
| 极轴 | 把赤道仪的赤经轴对准天球极的过程。 | 对赤道仪长曝光和场旋转控制很关键；看不见北极星时要按所用设备支持的方法规划。 |
| 子帧 / Light | 同一目标的一张原始曝光。 | 不是“废片或成片”的二选一；多张合格子帧才形成可整合数据。 |
| Flat、Dark、Bias、Dark Flat | 分别用于校正光路不均、热/固定图样或读出状态的校准数据。 | 匹配关系不同，首拍先用[校准帧现场速查卡](/03-拍摄SOP/校准帧现场速查卡.md)记录。 |
| 配准 | 把各子帧中的星点对齐。 | 未配准就不能可靠整合；配准结果也能暴露失焦、拖线或误指向。 |
| 叠加 / 整合 | 将经过筛选、校准和配准的多张子帧合成为主图。 | 目标是改善信噪比，不会把严重失焦或错误校准自动变好。 |
| 线性主图 | 尚未进行强拉伸的整合结果。 | 看起来偏暗或灰并不等于失败；它是后续背景、色彩和拉伸的可复处理母版。 |
| 拉伸 | 把弱信号显示到人眼可见范围的非线性显示/处理步骤。 | 应晚于输入质量、校准和整合的基本检查。 |
| 视场 | 相机与光学系统实际覆盖的天空范围。 | 用规划软件和实际构图确认，不能只按目标名称或焦距猜测。 |

## 首晚不变的记录卡

无论你走哪条路线，至少留下这些信息：日期与地点类型、目标、光学组合、相机或设备模式、实际曝光组、天气/露水异常、校准帧选择、文件存放位置。它让第二天的后期和下次改进不必依赖记忆。

## 不要在这里找的答案

- 具体型号是否兼容：回到厂商当前手册和[系统兼容性清单](/01-新人入门/购买前成像系统设计与兼容性清单.md)逐项核对。
- 某个目标今晚能否拍：回到城市首拍页，用实际时间、地平遮挡、月亮和视场验证。
- 某一帧的唯一故障根因：回到诊断页，先保留连续原片和日志，避免凭截图武断下结论。
