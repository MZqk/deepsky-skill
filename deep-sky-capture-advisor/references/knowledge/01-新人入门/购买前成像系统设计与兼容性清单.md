# 购买前成像系统设计与兼容性清单

**摘要**：不要把“望远镜、相机、赤道仪各自能用”误当成“整套系统能运行”。购买或升级前，应为目标、场地、光路、机械、供电、控制平台、数据与安全各建立一项可验证记录；只有“能接、能合焦、能供电、能控制、不会碰撞、能保存数据”全部通过，才进入下单或首夜测试。

## 背景 / 适用场景

适用于首套深空成像系统和任何会改变系统接口的升级：主相机、减焦/平场镜、滤镜轮/抽屉、OAG、调焦器、控制盒、赤道仪、电源或迷你电脑。本文不做品牌排名，也不替代具体型号的说明书。

## 先定义约束，而不是先挑型号

| 要回答的问题 | 记录内容 | 为什么必须先写 |
|---|---|---|
| 拍什么、在哪里拍 | 目标类型、可见高度、城市/暗场、单次可用时长、是否需携带 | 决定焦距、滤镜、总重量和电池需求。 |
| 如何控制 | Windows + N.I.N.A./ASCOM、INDI/Ekos、厂商控制器或手动流程；操作系统与版本 | 同一设备在不同平台上的驱动和功能边界可能不同。N.I.N.A. 明确区分原生支持与 ASCOM 设备支持。[官方说明](https://nighttime-imaging.eu/docs/master/site/requirements/) |
| 是否无人值守 | 全程在场、短时离开或远程/屋顶台 | 决定是否需要安全监视、硬件限位、停泊和人工接管方案。 |
| 可接受的复杂度 | 是否愿意管理滤镜轮、OAG、电脑驱动、校准库与多夜处理 | 复杂度本身是成本；缺一条连接链，整套设备都无法工作。 |

## 必填的系统兼容性表

在购买前建立一张表。信息来源要标记为“厂商说明”“已实测”或“未知”，未知项不应靠猜测通过。

| 子系统 | 必填字段 | 通过条件 |
|---|---|---|
| 主光学 | 镜筒/改正镜型号、焦距、焦比、像圈、改正镜的参考面与目标间距 | 厂商明确给出成像要求；相机与附件能在规定间距内安装。 |
| 相机与光路 | 传感器尺寸、相机传感器面位置、滤镜轮/抽屉/OAG/倾斜环和每个接环厚度、螺纹规格 | 光路预算有余量，末级有效通光口径不会形成不可接受暗角。详见[成像光路：后截距、像圈与接口预算](/02-器材百科/成像光路：后截距、像圈与接口预算.md)。 |
| 机械 | 赤道仪摄影载荷定义、完整成像列单、镜筒伸臂、鸠尾板/鞍座规格、三脚架/立柱 | 按厂商定义核算后仍有余量；真实镜组和线缆可完成东/西侧全行程。 |
| 供电 | 每台设备的允许电压、极性、插头、正常/峰值电流、单口与总口限流、线缆长度 | 每条支路有清晰来源与带载测试计划，不把“同为 12 V”视为可任意互接。 |
| 数据与连接 | USB/网络端口、线缆类型、存储介质、采集软件、驱动/固件版本 | 白天可同时识别全部设备、完成试拍并保存原始文件。 |
| 导星与自动化 | 导星方式、控制连接、子午线翻转、停泊/限位、天气/人工接管 | 翻转与停泊不发生机械干涉；异常时知道谁会停止曝光、谁会断电或需要人工处置。 |

## 五道兼容性闸门

1. **软件闸门**：先在厂商页面确认设备是否被所选平台支持、通过原生驱动还是 ASCOM/INDI/Alpaca 驱动，并记下版本。ASCOM 是接口标准，不等于所有驱动都已安装、所有特性都能在某软件中使用；厂商控制器也可能对相机或调焦器有专属支持范围。[ASCOM 文档中心](https://ascom-standards.org/Documentation/Index.htm)与设备兼容列表应逐项核对。

2. **光学闸门**：以改正镜/减焦镜的实际参考面为起点，累计相机传感器面、滤镜轮、OAG、抽屉和接环的长度。55 mm 只是部分模块化组合的示例；后截距会随光学结构和附件变化。[Celestron 的说明](https://www.celestron.com/blogs/knowledgebase/understanding-your-telescope-s-back-focus)列出了明显不同的系统间距。

3. **机械闸门**：以完整镜组而非裸镜筒检查鞍座、鸠尾板、重心、调焦器承载、镜尾挠度和三脚架刚性。配重用于平衡，不应直接混入厂商的“摄影载荷”定义；最终是否可用，以实际星点和稳定性验收。

4. **供电闸门**：记录每台设备的电压、插头和端口/总输出限制；在“赤道仪 GoTo + 相机制冷 + 防露 + 控制电脑”同时运行时测负载端电压。细节见[供电、线缆与现场运行安全](/03-拍摄SOP/供电、线缆与现场运行安全.md)。

5. **运行闸门**：在白天用真实镜组、所有线缆和露带完成连接、对焦行程、赤道仪东/西侧运动、子午线翻转与停泊干跑；首夜只验证已通过的组合，不在黑暗中首次拼接关键部件。

## 下单前最小验收清单

- [ ] 每个部件都有准确型号、说明书链接、来源日期和退换/保修条件。
- [ ] 主光路有一张从改正镜参考面到传感器面的长度表；未知接环厚度未被忽略。
- [ ] 传感器尺寸、像圈、滤镜有效通光口径和末级开口已一起核对，不只比较传感器对角线。
- [ ] 选定控制平台后，全部设备都有可用的驱动/连接路径和版本记录。
- [ ] 供电图包含输入与输出端口限制、极性、线缆和峰值负载；没有用转接头“碰运气”。
- [ ] 已定义翻转/停泊的机械包络和异常后的人工处置方式。
- [ ] 有数据落盘位置、剩余容量和一份会话记录模板。

## 示例：一页式系统卡

```text
场地与目标：城市阳台；以发射星云为主；每晚在场 4 小时
控制平台：Windows + N.I.N.A.；驱动版本与下载页已记录
主光路：镜筒/改正镜型号 → OAG → 滤镜轮 → 相机
参考面预算：厂商目标间距 ___ mm；已装长度 ___ mm；待确认接环 ___ mm
机械：完整成像列单 ___ kg；东/西侧翻转与线缆干跑：未测 / 通过 / 不通过
供电：输入规格与每条支路限制已记录；峰值带载测压：未测 / 通过 / 不通过
数据：原始文件目录、可用空间、会话 manifest、备份位置已创建
阻塞项：____________________________________________
```

## 权威问答口径

- “能被控制软件发现”不等于整套系统兼容。回答具体兼容性问题时，必须同时核对当前操作系统、设备驱动/协议、控制软件支持范围和实际连接测试；N.I.N.A. 官方要求页只证明其自身的平台与设备支持边界。[^src-nina-requirements][^src-ascom-docs]
- 后截距必须按具体望远镜、改正器或减焦器制造商给出的基准面和目标距离核算，不能把常见的 55 mm 当作跨产品标准。[^src-celestron-back-focus]

## 注意事项

- 看到“兼容”宣传时，继续问清楚它指机械螺纹、合焦、像圈、驱动识别还是自动化功能；它们不是同一件事。
- 不把论坛搭配图或某一品牌的接环图当成自己的光路尺寸；改正镜和相机的参考面必须匹配实际型号。
- 首次引入相机、滤镜轮、控制器或固件时，先保留已知可用配置与安装包；不要在晴夜做不可回滚的多项升级。
- 未通过“翻转不碰撞、带载不断电、试拍可落盘”的系统，只能有人在场测试，不能无人值守。
