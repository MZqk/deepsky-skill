# 后期软件对比

**摘要**：DeepSkyStacker、Siril 与 PixInsight 的差异主要在平台、授权、自动化方式、预处理/处理范围和学习成本。选择时应从自己的数据类型、操作系统、可复现要求和预算出发，并用同一组素材比较输出与操作成本；不存在脱离任务和版本的通用“算法最强”结论。

## 背景 / 适用场景
适用场景：校准帧与亮场整合、背景处理、色彩校准、去噪、锐化、星点处理和窄带合成。软件的平台、版本、插件、授权和功能会变化；本文只给选择框架，安装前应回到各自官网确认当前支持范围。[^src-96e42590] [^src-62ab6b49] [^src-17db8e44]

## 核心知识点
- DeepSkyStacker (DSS)：主要面向 Windows 的校准与叠加工作流，适合希望用图形界面快速完成基础整合的人。输入格式、相机 RAW 支持和维护版本应以官网为准。[^src-17db8e44]
- Siril：免费开源，覆盖预处理与多种后续处理，并提供脚本和序列工作流；适合希望跨平台、保留处理步骤并逐步学习天文预处理的人。具体脚本输入目录和校准逻辑应按当前官方文档核对。[^src-847b6a49]
- PixInsight：付费授权、模块化并支持复杂的可复现流程；WBPP、原生工具与第三方插件的能力和授权彼此不同，不能把某个插件效果写成 PixInsight 本体的统一保证。安装、许可、系统支持、文档与支持入口先看[官方 FAQ](https://pixinsight.com/faq/index.html)，它是导航而不是处理配方。[^src-62ab6b49] [^src-pixinsight-faq]
- 学习成本不是固定排名：熟悉脚本或命令行的用户可能更快掌握 Siril，已有图像处理经验的用户也可能直接采用 PixInsight。应以完成同一数据集的校准、整合、记录与复做为比较任务。
- 选择建议：只需基础 Windows 叠加可先试 DSS；希望免费跨平台并覆盖预处理与基础处理可先试 Siril；确有复杂流程、团队规范或特定模块需求时再评估 PixInsight。先用自己的素材和试用/免费路径验证，不按“新手/高手”标签购买。

## 注意事项
- 大尺寸、大量帧和多通道工程应先做小样本与磁盘空间测试；软件选择取决于数据规模、流程和硬件，不能仅凭产品名称判断能否完成。
- 校准帧要与亮场同设置（温度/增益/曝光/分辨率/光路），否则平场/暗场失效引入梯度或热噪。
- 文件路径、格式和脚本限制以所用软件当前版本为准；若遇到读取失败，先保留原路径与日志，再用最小样本验证是否确为字符或权限问题。
- PixInsight 是付费授权，团队批量部署需合规授权；勿用破解版。
- 叠加后仍需‘处理’（背景、色彩、去噪、锐化）才出片，叠加软件≠后期全部；新手易误以为 DSS 出图即成品。

## 示例
- 新手最快路径：DSS 导入暗/平/偏 + 亮场 → 向导式叠加 → 得到初步校准后的 FIT/TIFF，再进 PS/GIMP 简单拉伸。
- 进阶路径：Siril 用官方 OSC/DSO 脚本做预处理叠加 → 用背景提取、色彩校准、去噪、asinh 拉伸等工具出图。
- 高手路径：PixInsight WBPP 做权重预处理叠加 → BGE/DBE 去梯度 → 色彩校准(PhotometricColorCalibration) → NoiseXTerminator/原生去噪 → 局部对比度与锐化 → 窄带通道合成。
