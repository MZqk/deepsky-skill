# 供电、线缆与现场运行安全

**摘要**：供电安全不是“买更大 Ah 电池”或“所有设备都接 12 V”。应按每台设备的允许电压、极性、连接器、单口/总口限制和启动峰值建表，在真实最大负载与最长线缆下测量负载端电压；再以线缆运动包络、天气和故障停机规则保护人员与设备。

## 范围与边界

本文适用于常见低压直流深空设备的运行管理，不提供市电接线、电池拆修、裸电芯组装或绕过保护电路的方法。交流供电、充电、电池运输、保险和场地规则必须遵循产品手册与当地法规；不确定时应停止接线并询问合格人员或厂商支持。

## 第一步：建立供电账本

不要估算“整套大概几安”。对实际将连接的每台设备填表；规格来自当前型号手册，而不是相似型号或论坛截图。

| 设备 | 允许电压 / 极性 / 接头 | 正常与峰值负载 | 接入的端口及单口/总口限制 | 线缆长度与规格 | 来源与验证状态 |
|---|---|---|---|---|---|
| 赤道仪 |  | 跟踪 / GoTo 峰值 |  |  | 厂商说明 / 已实测 / 未知 |
| 主相机与 TEC |  | 曝光 / 制冷拉升 |  |  |  |
| 控制电脑/控制盒 |  | 空闲 / 高负载 |  |  |  |
| 防露、调焦、滤镜轮、USB Hub |  | 关闭 / 最大设置 |  |  |  |

同为“12 V”不代表插头、极性、耐压、单口限流或总输出能力相同。以 ASIAIR 等控制器为例，厂商会分别给出输入范围、单口与总输出限制；任何控制器都应按**所购具体型号的当前手册**核对，而不是因接口外观相同就互接。[厂商 FAQ 示例](https://www.zwoastro.com/product-faqs/)

## 容量预算：用 Wh 起算，用带载测试收尾

电池的标称能量可先用 `Wh = 标称电压 × 标称 Ah` 估算。它不是整晚可用能量的保证：低温、放电率、电池管理系统、转换损耗和设备峰值都会改变实际续航。

1. 记录每个工作状态的实际功率或电流：待机、赤道仪 GoTo、相机 TEC 拉升、防露最大档、电脑高负载。
2. 以计划运行时长估算能量，并为低温与异常恢复保留由实测决定的余量；不要套用固定“总电流 × 某倍数”。
3. 首次使用时，开启最重负载组合，测量**电源端和负载端**电压/电流，记录电压最低点和是否发生重启、掉线或相机异常。
4. 将测试结果写入会话记录；下一次增加防露、电脑、相机或更长线缆后重新测试。

Pegasus 的运行指南指出，长而细的 DC 线、转接头和高负载会引发压降，并可能造成相机、赤道仪或小型电脑异常；这说明“空载能亮”不等于带载可用。[线缆建议](https://pegasusastro.com/cable-management-recommendations/)

## 配电与线缆原则

- **从源头开始核对**：电源、分配器、控制盒、保险/保护和每条支路都必须满足对应设备手册的电压、极性与额定值。不要把未知转接头、松动插头或反向接线接入贵重设备。
- **把高峰值写出来**：赤道仪 GoTo、相机 TEC、防露和电脑启动可能同时出现峰值。必要时按设备手册把支路隔离，避免一个支路故障拖垮整套系统。
- **在负载端测压**：电压警告、重启、条纹噪声、掉 USB 或赤道仪异响都可能与供电或线缆有关。先检查源端、负载端、转接头和线路温度，再判断软件问题。[Powerbox 故障排查](https://pegasusastro.com/troubleshooting/powerbox-troubleshooting-guide/)
- **短、牢、可释放**：电源和 USB 线尽量短且有应力释放；避免紧绷、锐折、缠在运动轴上或形成可能勾住配重的环。数据线与电源线不宜长距离紧绑；实际表现仍以整套系统测试为准。
- **USB 不只看长度**：相机、硬盘、Hub 与电脑应在白天满负载试传输；需要 Hub 时确认其供电方式、端口能力和低温适用性。不要在正式序列中首次使用陌生的延长器或扁平线。

## 线缆运动包络与翻转测试

软件只能发出翻转和停泊命令，不能替你判断线缆、露带、相机或配重会不会碰撞。每次更换镜组、加装 Hub/电源盒或改变线束后，白天完成下列干跑：

1. 用真实镜组、相机、露带和全部线缆通电，但先不开始自动序列。
2. 在东侧和西侧分别移动到接近最低安全高度、目标高度和预期翻转位置；观察线缆是否拉紧、绕轴、勾配重或碰三脚架。
3. 在有人看守下执行一次翻转与停泊；确认线缆仍有余量，接头没有受力，导星/相机/USB 没有掉线。
4. 记录允许的方向、禁入区域和需要重新测试的变更（镜筒长度、线缆、相机、露带、控制盒位置）。

## 防露、天气与电池安全

- 防露带是持续负载，应计入供电账本。以“刚好防露”为目标，结合镜面状态、露点、风和露罩调整，不用固定温差代替观察。
- 发现接头受潮、端口进水、线缆破皮、异常发热、焦味、冒烟或反复重启时，停止拍摄并断开受影响支路；不要反复通断电“试试看”。
- 雷暴临近、听到雷声或当地预警要求避险时，应停止户外架设和运行，撤至安全场所。NWS 的原则是雷暴在附近时没有安全的户外位置。[雷暴安全说明](https://www.weather.gov/safety/lightning-safety-overview)
- 只使用完整、有保护的成品电池和匹配充电器，不使用来源不明、拆包、改包或裸露锂离子电芯。CPSC 特别警示未受保护的散装 18650 电芯短路和热失控风险。[安全警示](https://www.cpsc.gov/Newsroom/News-Releases/2021/CPSC-Issues-Consumer-Safety-Warning-Serious-Injury-or-Death-Can-Occur-if-Lithium-Ion-Battery-Cells-Are-Separated-from-Battery-Packs-and-Used-to-Power-Devices?language=en)

## 异常时的安全动作

| 触发信号 | 立即动作 | 恢复前必须确认 |
|---|---|---|
| 低压告警、设备重启、赤道仪失步或 USB 反复掉线 | 停止曝光；避免在不稳电压下继续 GoTo/翻转；检查源端与负载端电压、线缆和转接头 | 实际峰值负载下电压稳定，问题支路已隔离或更换。 |
| 线缆被拉紧、勾住或接头随镜组受力 | 立即停止运动；必要时人工支撑镜组后按设备手册安全断电 | 线缆重新走线并重新完成全行程测试。 |
| 接头发热、焦味、烟、水汽进入电气部件 | 断开电源，远离可燃物；不要继续使用受损部件 | 由厂商/合格人员确认，或更换受损组件。 |
| 雷暴、强风、降雨/结冰风险 | 停止序列，优先人身安全；在条件允许且不增加风险时做安全收机 | 天气和场地条件恢复，设备干燥且功能通过复测。 |

## 出队检查清单

- [ ] 每条供电支路的电压、极性、接头和限制已核对。
- [ ] 电池、分配器、控制器和线缆外观完好、干燥、无松动。
- [ ] 最大负载带载测试通过；负载端没有异常掉压或重启。
- [ ] 线缆已做应力释放，东/西侧全行程、翻转与停泊干跑通过。
- [ ] 防露负载、天气预报、撤收路径和人工停机方式已确认。
- [ ] 会话日志记录了电源来源、起始电压和任何异常。

## 权威问答口径

- 电源连接必须遵守设备官方允许电压、极性、端口电流和总功率限制，并在最大实际负载与最低预期温度下测量负载端电压；“同为 12 V”不能证明端口可互换。[^src-pegasus-cable][^src-pegasus-powerbox][^src-zwo-faq]
- 听到雷声或收到雷暴威胁时应停止户外作业并进入封闭建筑或硬顶车辆；帐篷、棚架和孤立树木不是安全避雷场所。[^src-nws-lightning]
