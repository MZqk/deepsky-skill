# 导星

**摘要**：导星用独立的导星相机持续监测一颗(或多颗)星，向赤道仪发送 RA/DEC 修正指令以减小跟踪误差。PHD2 的基础流程是：为具体设备建立 Profile → 用 Calibration Assistant 校准 → 用 Guiding Assistant 和日志验证。RMS 是诊断指标，不是跨设备的合格线；应结合主相机采样、视宁度及实际星点圆度/FWHM 判断。导星镜与 OAG 的取舍取决于焦距、刚性、镜筒行为和导星星条件，而非单一焦距阈值。

## 背景 / 适用场景
适用：赤道仪+导星系统长曝光。前置：极轴已校准、导星相机已合焦、镜组平衡、设备已连接 PHD2(或经 N.I.N.A 联动)。导星只修正跟踪误差，不修正场旋转(那要靠极轴)也不修正星点虚焦。

## 核心知识点
- 原理：导星相机视场内监测星点位移，PHD2 计算后给赤道仪发脉冲修正。RA/DEC 修正量取决于极轴误差、赤纬、风、回差、周期误差和连接方式；不能用“DEC 越少越好”替代主相机星点与日志验收。[^src-phd2-basic-use]
- PHD2 设置流程：①读当前官方手册；②用 Setup Wizard 建立设备与 Profile；③先把导星相机对好焦；④启用 Multi-star guiding；⑤仅在 PHD2 能通过 ASCOM/INDI 或 Aux Mount 获得可靠指向信息、且导星相机未旋转时，再考虑恢复既有校准；⑥在无遮挡且适合校准的天空位置完成校准。[^src-phd2-basic-use]
- 校准(Calibration)：软件通过在 RA/DEC 方向移动导星星建立校准矩阵，所需步数与位移由导星尺度和设置共同决定，不应把固定像素数当作通用目标。首次建立 Profile、导星相机旋转、导星焦距/硬件/连接方式改变，或校准图形异常时应重新校准。若有可靠的指向信息，PHD2 可按赤纬和子午线翻转变换校准数据；换目标或翻转本身并不自动意味着必须重校。没有指向信息或翻转行为不明时，应按当前文档验证翻转校准或重新校准。[^src-phd2-advanced-settings]
- RMS 与成像验收：PHD2 报告 RA、DEC 与总 RMS（角秒），可用于发现风振、回差、周期误差或设置问题。不要把某个 RMS 数字当作合格线；应同时检查主相机的星点圆度、FWHM、成像采样和当晚视宁度，并在同一设备上比较趋势。
- 导星参数：从 Profile Wizard 和 Guiding Assistant 的建议开始，随后用足够长的日志验证。Predictive PEC、min move、backlash compensation 与 aggression 都依赤道仪和实际曲线而定；不应预设某一种算法适合所有 RA 轴。
- 导星曝光与尺度：以稳定检测导星星、不过度追随视宁度且能及时响应误差为准。导星镜焦距没有必须达到主镜某一比例的通则；应结合导星采样、信噪、机械刚性和主相机星点结果评估。
- OAG vs 导星镜：导星镜安装简单、导星星较多，但可能出现差动挠曲；OAG 让导星相机看到主光路位移，通常能减轻差动挠曲和移动主镜带来的问题，但仍须正确合焦并保证机械刚性。长焦或移动主镜系统常更适合 OAG，具体取舍应以星点和日志验收，而非硬性焦距门槛。
- 与 N.I.N.A 联动：采集软件可通过 PHD2 服务接口启动/停止导星并触发 dither。具体动作名称、稳定等待和失败处理会随采集软件版本变化，应按当前版本文档配置，并用短序列验证。[^src-phd2-basic-use]

## 权威问答口径

- 本页可承担的回答范围：通过 PHD2 或兼容平台进行导星的赤道仪深空长曝光系统；成立条件：完成正确标定、Guiding Assistant 检查，并以主相机星点和导星日志共同验收。
- 遇到以下情况必须拒绝确定结论或转入专项页/实测：把固定 RMS 或算法参数套用于所有焦距、采样和视宁度；仅凭图表远程确诊。
- 具体数值、兼容性、软件行为或安全结论只使用正文就近绑定的来源，并同时受 `stale_after` 与人工 `verified.scope` 限制。


## 注意事项
- 导星相机没合焦就校准/导星必失败，白天可对远处目标粗合焦、夜里再细调。
- 导星镜装在 finder shoe 上易挠曲，应刚性固定(镜环+鸠尾)。
- RMS 异常先查看主相机星点、风、线缆、极轴、平衡与 PHD2 日志，再小幅调整参数；不要只靠调高 aggression 掩盖机械问题。
- Calibration Assistant 会让镜筒转动到子午线附近，务必确认周边无遮挡、三脚架不撞腿。
- 自动恢复校准只适用于设备几何关系未改变、导星相机未旋转且 PHD2 有可靠指向信息的 Profile；运输、旋转相机、改动焦距/连接配置后应重校。翻转后是否重校取决于连接方式和已验证的翻转校准。
- OAG 找不到导星时长焦窄带常见，可加亮星或换区/降 binning；不要因此硬上导星镜牺牲精度。

## 示例
- PHD2 起步流程：Setup Wizard 建 Profile → 导星相机合焦 → 启用 Multi-star guiding → Calibration Assistant 校准 → Guiding Assistant 生成起始建议 → 以主相机测试帧和 PHD2 日志验证，再按问题逐项微调。
- 导星镜选型示例：短焦折射(430mm)配 ZWO 30mm f/4 mini 导星镜 + ASI290MM Mini(小像素采样好)；长焦(RC 2000mm)改 OAG + 同品牌相机。
- 合格线参考：记录同一设备、相近目标高度下的 RMS、FWHM、偏心率和拒片率，建立自己的基线；若主相机星点稳定圆润且日志无异常，不必为了追逐固定 RMS 数字频繁改参数。
