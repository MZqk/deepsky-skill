# 校准与叠加

**摘要**：叠加（Stacking/Integration）是把多张亮场经正确校准、配准、质量筛选与整合，提升信噪比的核心步骤。PixInsight 的 WBPP、Siril 与 DSS 均可完成其中一部分或全部流程。校准帧、拒绝算法与 Drizzle 都应由相机特性、帧数、抖动覆盖和验收图决定；不存在“现代 CMOS 一律省暗场”或“少帧一律用某算法”的通用配方。

## 背景 / 适用场景
需要：单张或多夜拍摄的亮场（Lights），以及按相机和帧类型匹配的校准帧（Dark、Flat、Bias 或 Dark Flat）。软件任选其一：PixInsight（WBPP 脚本，付费）、DeepSkyStacker（Windows 免费）、Siril（跨平台开源免费）。叠加前先检查子帧与主校准帧，剔除明显卫星/飞机划痕、严重拖线、失焦或异常背景的帧。

## 核心知识点
- 校准帧作用：Bias 记录最短曝光的电子偏置；Darks 处理热噪与 amp glow 等固定图样；Flats 校正暗角与灰尘。先按帧类型建立匹配关系：Dark 对应 Light、Dark Flat 对应 Flat；是否用 Bias 或 Dark Flat 校正 Flat，取决于相机与软件流程。
- PixInsight WBPP（Script > Batch Processing > WeightedBatchPreprocessing）：一次导入 Lights/Darks/Flats/Bias，自动完成 Calibration → Registration → Frame Rejection → Weighting → Integration → Drizzle → Auto Crop。
- WBPP 加权：PSF Signal Weight 综合星点质量、信噪、背景等质量信息，不只是 FWHM；无论采用何种权重，都应抽查被降权或剔除的帧是否符合实际画质。
- 像素拒绝（Integration Parameters > Pixel Rejection）：先保留 Auto 或按软件文档选择，再检查 rejection map。算法适用性受帧数、异常类型和信号强度影响；不要以“少帧必用 Winsorized”或“帧干净必用 GESD”代替验收。
- Exposure Tolerance：用于相近曝光帧的匹配分组，不应用来把物理条件明显不同的 300s 和 600s 帧强行视为同一组。若确需合并不同曝光，先分组校准、检查归一化与噪声，再有意识地整合。
- Drizzle Integration（DrizzleIntegration 模块）：利用子像素偏移重建有效分辨率，前提是采样与抖动覆盖足够好；没有跨相机通用的最小帧数，先检查抖动、覆盖和输出噪声再决定是否使用。
- 坏帧处理：叠加前用 Blink 逐帧查看，删除明显卫星/飞机轨迹、严重拖线、失焦帧；也可在 WBPP 的 Calibration 标签页用 Show Calibration Diagram 核对各滤镜是否正确匹配对应平场（避免 OIII 平场去校准 Ha 亮场）。

## 权威问答口径

- 本页可承担的回答范围：可导出原始子帧并由 Siril、PixInsight 或同类软件处理的数据集；成立条件：校准匹配、配准参考、拒绝算法和权重按数据分布及软件版本验证。
- 遇到以下情况必须拒绝确定结论或转入专项页/实测：将一种拒绝参数用于所有帧数和异常分布；对专用机内堆栈强制重新校准。
- 具体数值、兼容性、软件行为或安全结论只使用正文就近绑定的来源，并同时受 `stale_after` 与人工 `verified.scope` 限制。


## 注意事项
- 不要为了得到一张主图而强行合并不同曝光、增益、滤镜或校准条件的 Light；先保持可追溯的分组，再验证归一化与整合结果。
- 过滤器（Filter）命名必须正确，否则 WBPP 会用错平场校准亮场，导致梯度/暗角。
- 是否省略 Dark 必须以该相机、曝光、温度下的主暗场和校准后残差为依据。省略 Dark 不会校正热像素或 amp glow；若改用 cosmetic correction，也应记录其局限。
- Drizzle 可能提升欠采样数据的细节，也可能放大噪声；以抖动覆盖、采样和实际输出比较判断，而非固定帧数阈值。
- 叠加量并非越多越好：SNR 提升遵循 √N 规律（叠加 N 张噪声降为 1/√N），到一定时长后边际收益递减；典型总曝光 4–10 小时，单项目 20–200 帧皆常见。
- 总曝光或帧数不足时，激进拒绝算法可能损失信号；应结合 rejection map、输出噪声与单帧质量复核参数。

## 示例
- 推荐流程（PixInsight WBPP）：按滤镜、曝光和相机状态导入 Lights；为每一组导入匹配的 Dark、Flat 与 Bias 或 Dark Flat → 先用默认匹配与 Auto 拒绝运行小批测试 → 检查校准图、加权结果和 rejection map → 仅针对发现的问题调整参数，再运行完整整合。
- 免费方案（Siril）：各滤镜分别执行 预处理（Pre-processing，自动调用 darks/flats/bias）→ 配准（Registration）→ 叠加（Stacking，默认 Winsorized Sigma Clipping）。
- 免费方案（DSS）：添加亮场 → 自动识别/添加校准帧 → 默认叠加，适合 Windows 新手快速出图。
- 叠加量示例：60 × 3 分钟 = 3 小时；进一步提升靠增加总曝光而非单张时长。15 张叠加的 SNR 已明显优于单张。
