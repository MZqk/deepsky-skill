# 滤镜系统

**摘要**：滤镜分宽带（LRGB，用于彩色合成与细节）与窄带（Hα 656.3nm / OIII 500.7nm / SII 671.6nm，选择性透过目标发射线附近的窄波段）。窄带可降低部分连续背景、提升发射星云对比，但不会消除月光或所有光害。OSC 可用双窄带取得 Hα/OIII 数据；单色可组合 LRGB 与窄带。滤镜尺寸须按光锥、滤镜—传感器距离和末级通光孔径核算。

## 背景 / 适用场景
用于深空星云/星系成像。LRGB 在暗空出真彩；窄带在光污染城市或拍发射星云(HII区、行星状星云、超新星遗迹)时不可或缺。需配合滤镜轮(单色)或前置滤镜(OSC)。

## 核心知识点
- LRGB：L(亮通道,宽带,无色彩,提细节与信噪比)+ R/G/B(色信息)合成真彩；L 用单色相机拍最锐，RGB 可短曝光。
- 窄带三剑客：Hα（氢α，656.3nm）、O III（双电离氧，500.7nm）、S II（单电离硫，671.6nm）；发射星云在这些波长有强发射线。
- 窄带带宽：常见 3nm / 5nm / 7nm。较窄的带宽可更强地隔离相邻谱线与连续背景，但实际信噪比还取决于中心波长、透过率、焦比、天空背景和目标谱线；不能仅凭“越窄”推断固定曝光或通用城市方案。
- 窄带抑光污染原理：窄带滤镜让目标发射线附近通过，并抑制大量不在通带内的连续背景。月光、空气辉光和部分人造光仍可能抬升背景或造成梯度，应通过试拍、总积分和后期本底校正处理，而非假定能全部滤除。
- 配色映射：经典 SHO = SII(红)/Ha(绿)/OIII(蓝)的『哈勃色』；HOO = Ha(红)/OIII(绿蓝)；城市常用 Hα+OIII 双窄带。
- 双窄带：如 L-eXtreme 这类滤镜让 Hα 与 OIII 附近的窄波段通过，OSC 单次曝光可同时收集两类信号，之后仍需按相机 Bayer 响应和处理目标决定配色。
- UV/IR cut：是否需要额外 UV/IR 截止，应核对相机保护窗/内置滤镜、镜头或望远镜的色差表现以及拍摄目标；许多 OSC 相机已带相应光学窗，不能一概而论。
- 滤镜尺寸与传感器匹配：传感器对角线不是唯一条件。应按焦比、滤镜到传感器的距离、滤镜有效通光口径和其他末级开口绘制光路或使用厂商计算器，并以平场验证是否有不可接受的暗角。

## 权威问答口径

- 窄带滤镜可以压低部分连续谱背景并提高特定发射线与背景的对比，但不能“消除光污染”或让目标本身变亮；带宽、中心波长和透过率只对具体产品成立。[^src-zwo-narrowband-filters]
- 滤镜选择必须同时说明目标光谱、相机类型、入射光锥、天空背景和颜色目标；对星系、反射星云等连续谱目标，不能把窄带当作宽带信号的通用替代。[^src-zwo-narrowband-filters]

## 注意事项
- OSC 使用单线窄带（如 Hα）时，主要由红色 Bayer 像素采样；它仍可用于单色、伪彩或补充信号，但不能直接替代完整彩色数据。是否选择双窄带取决于目标和后期方案。
- 滤镜尺寸买小可能产生暗角，但不能只以传感器尺寸或“1.25 英寸/2 英寸”作判断；先核对有效通光口径和滤镜—传感器距离，再用平场验收。
- 窄带不能替代极轴/导星：它只管信噪比，不解决跟踪。
- 干涉型窄带滤镜在快焦比系统的较大入射角下，中心波长会向短波（蓝端）偏移。购买前应核对厂商标注的适用焦比：慢系统通常使用标准版本，快速系统可能需要为快焦比预移位/Highspeed 的版本；不能把“快镜更友好”当作通用结论。
- LRGB 中 L 与 RGB 需共焦(同焦点)，否则合成发虚；用巴洛/平场确认齐焦。
- 滤镜螺纹与相机/减焦镜前端口径一致(多数为 M48 2″)；注意后截距变化。

## 示例
- OSC 入门窄带：可考虑 Hα/OIII 双窄带；先核对目标、相机光学窗、系统焦比和滤镜规格，再决定是否适用。
- 单色进阶：L(RGB)+ Ha(7nm)+ OIII(7nm)+ SII(7nm) 滤镜轮(36mm)，拍 SHO。
- 宽带真彩：LRGB 套装(各自带宽约 全可见，L 含 UV/IR cut)。
- 尺寸匹配：同一台相机在不同焦比、滤镜位置和接环结构下所需有效口径不同；按实际光路计算并用平场验证。
- 城市实战：以短测试序列比较不同滤镜下的背景、星点、目标信号与梯度，再决定带宽、单张曝光和总积分。
