# AI 常见误判案例

## 极暗不等于最强降噪

- 错误判断：画面很暗、噪声占主导，因此直接使用最高降噪强度。
- 正确判断：暗弱信号与噪声同时很弱；先检查局部 SNR 和高频能量，渐进降噪并复查纤维结构。
- 反例画面：背景光滑，但星云微弱外缘一起消失。
- 正例画面：背景仍有轻微自然颗粒，星云外缘连续可辨。

## 背景偏红不等于严重偏色

- 错误判断：整图红色占优，必须强制灰度世界校准。
- 正确判断：Hα 丰富天区天然偏红；先在无星云背景采样，再决定是否中性化。
- 反例画面：校准后 Hα 云气变灰、红色结构失去层次。
- 正例画面：背景中性，但发射区仍保留深红。

## 密集星场不等于最大缩星

- 错误判断：星点覆盖高，统一使用最大缩星。
- 正确判断：先区分宽场发射星云与球状/疏散星团；星团中星点就是主体。
- 反例画面：球状星团核心被腐蚀成不自然的小孔。
- 正例画面：核心恒星可解析，外围星点自然递减。

## 拉伸后中位数偏低不等于拉伸不足

- 错误判断：中位数低于 0.05 就继续提亮。
- 正确判断：暗星云和分子云依赖暗部剪影；结合目标类型、核心溢出率和用户意图判断。
- 反例画面：暗尘埃被抬灰，轮廓对比消失。
- 正例画面：背景电离气体可辨，暗结构仍保持深沉。

## 外部 AI 工具相关误判

### AI 降噪"干净"不等于无损失

- 错误判断：NoiseXTerminator 输出看起来比内置降噪干净得多，应该总是优先使用。
- 正确判断：AI 降噪在统计意义上估计信号，但可能在暗弱纤维区域过度涂抹。使用 `validate_external_denoise()` 验证高频能量比，低于 0.5 即有过度涂抹嫌疑。
- 反例画面：星云外缘细丝消失，暗区呈现不自然的"塑料感"均匀。
- 正例画面：背景干净但仍有轻微自然纹理，星云细丝连续可辨。

### AI 去星"无残留"不等于无损

- 错误判断：StarNet++ 几乎零残留，比形态学方法好，应默认使用。
- 正确判断：StarNet++ 在极暗区域可能误判星云细丝为星点（"挖洞"），在明亮星云核心可能留下修补痕迹。必须对 AI 去星结果做 CP3 视觉审查。
- 反例画面：暗弱星云丝状结构出现"挖洞"，亮星云核心有不自然的模糊斑块。
- 正例画面：星云纹理完整，残留星极少，修补区域过渡自然。

### AI 超分辨率"更清晰"不等于真实

- 错误判断：ESRGAN 输出看起来更清晰、细节更多，适合提升天文照片分辨率。
- 正确判断：AI 超分辨率是在噪声基底上"幻觉"出结构——这些亚像素细节在原始数据中不存在，在天文摄影中等同于数据造假。
- 反例画面：星云中出现原图不存在的纤维结构，暗尘埃边缘出现伪锐化纹理，星点周围出现 AI 生成的不自然光晕。
- 正确做法：增加实际曝光时间和叠加帧数来提升真实分辨率，而非依赖 AI 生成。

### AI 着色"更好看"不等于更准确

- 错误判断：AI 自动着色让星云颜色更丰富，提升了画面表现力。
- 正确判断：天文色彩来自发射线物理（Hα 656nm 红色、OIII 500nm 青蓝），AI 着色模型不理解这些物理约束，必然引入色彩失真。
- 反例画面：Hα 区域出现品红色偏移（AI 将部分红色映射为紫色），OIII 区域出现电蓝色（AI 增强蓝色通道），暗区出现不自然的绿色/青色。
- 正确做法：使用 PCC 测光法校准或灰度世界白平衡，结合 `emission` 模式保护 Hα 信号。

### 饱和度提升"更浓"不等于更准

- 错误判断：提高饱和度就是乘大 HSV 的 S，颜色更浓更"抓眼"。
- 正确判断：HSV 的 S 乘法保持 max 通道不变、把 `(max−min)` 拉开。当 G≠B 时，两个非最大通道被**不等比例**压向 0 —— 对红主导的 Hα 区，OIII 的 G/B 会被一起压掉。实测纯公式（×1.32）：`[0.25,0.10,0.06]` 的 B 直接归零（B/G 保留率 **0%**），`[0.50,0.15,0.09]` 同样归零。真实管线实测成片 `B/G 0.48 → 0.57`、`R/G 2.22 → 1.77`（改用保比例公式后）。
- 反例画面：双窄带的青蓝电离区被抹成暗红，整片星云呈"纯红剪影"；R/G 被推到 2.5 以上而 B/G 掉到 0.5 以下。
- 正确做法：用**保亮度/保比例**公式（以像素均值为轴：`new = mean + (x - mean) * k`）。弱通道只按其偏离均值的比例缩放，未越界裁切时逐像素均值严格不变。注意保比例公式在**同因子**下比 HSV S 乘法更淡，这是保住弱通道的必然代价。
- **管线里有两处**都要守这条规则：Phase 8 `final_color` 的 `color_tools.enhance_saturation`（因子 1.45，破坏更重——`[0.25,0.10,0.06]` 的 B/G 被压到 **0.088**）与 Phase 9a `style` 的 `apply_professional_style`（因子 1.32，同例 B/G 被压到 **0.000**）。只改一处不够。

## 星点伪影症状 → 原因 → 本地对策速查表

每条必须能指回本地的具体参数或门禁函数，否则就是空话。

| 症状 | 原因 | 指回本地 |
|---|---|---|
| 亮星暗环（黑圈） | 反卷积/锐化振铃；去星修补发黑 | `artifact_gates` **STAR_RINGING**；检查 `--deconv-iterations` 8~12、`sharpen_amount` |
| 星点胀大（整体变大） | 裸 STF 硬拉伸；无蒙版 LHE/CLAHE | `artifact_gates` **STAR_BLOAT**；改用 `masked_ghs` 或设 `ghs_hp` |
| 星点位置暗坑/发黑 | 去星过腐蚀；形态学修复过度 | `artifact_gates` **STAR_HOLES**；检查 `star_tools.py` 置信度，优先外部 StarNet++ |
| 星点丢失/压成灰斑 | 缩星过强；降噪抹掉暗星 | `artifact_gates` **STAR_LAYER_LOSS**；回落 `star_reduction`、提高 `star_threshold` |
| 核心死白/烧毁 | 拉伸+锐化叠加；`ghs_hp` 过小 | `artifact_gates` **CORE_BURNING**；提高 `ghs_hp` 或降低 `sharpen_amount` |
| 亮星紫晕/彩晕 | 色差折射镜；去星后色度未平整 | `--halo-guard`（去星后 2~4×FWHM 色度平滑）；外部 BXT `adjustStarHalos=0.00` |
| 绿色背景 | 校色未跑 / SCNR 误用 | `color_tools` 是否执行、`star_scnr_strength` |
| 拉伸坍缩（暗部压成窄带） | 极暗数据裸 GHS | `ghs_lp` 设为背景水平（如 0.001） |
| 高光均匀斑块 | headroom 过度压缩 | `ghs_hp` 别低于 0.05（发射星云）/ 0.10（星系 L） |

## 星点相关禁止动作清单

| 禁止 | 原因 | 替代 |
|---|---|---|
| 无蒙版 LHE/CLAHE | 胀星 + 放大天空噪声 | `local_enhance` + 蒙版保护 |
| 裸 STF 硬拉伸 | 星点胀大、核心过曝 | `masked_ghs` / 带 `hp` 的 GHS |
| 星系场激进缩星（>0.25） | HII 区/旋臂结被卷入 | 保守缩星（≤0.25）+ 强制蒙版保护 |
| 对已拉伸图跑线性算子 | 语义错配（线性反卷积、线性降噪） | 按 `cv_guardrails.md` 状态契约，线性阶段只做线性操作 |
| 线性数据用 SXT/StarNet `-n/--unscreen` | Screen 混合层与线性数据语义冲突 | 线性用 `-m/--mask`（可加性），非线性才用 `-n/--unscreen` |
| 一次 NXT 重手降噪（denoise>0.5） | 塑料感、暗星丢失、边缘模糊 | 多次轻量（denoise=0.25, detail=0.15）分阶段应用 |
