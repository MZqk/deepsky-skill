# 分区权重叠加法（PWS）方法参考

本文档是论文《分区权重叠加法的原理与实现》（D.Cikey，v3.1，2026-10-05）的技术提炼，供调用 PWS 叠加引擎的 agent 选择参数、解释结果之用。数学一律写成终端可读的纯文本形式，不引用 LaTeX 定界符；公式编号沿用论文原编号（如「论文式 6」）。

---

## 1 方法一句话与三类权重

**一句话**：先逐像素判定「此处是细节型还是朦胧型」，得到一个取值于 [0,1] 的连续分区场 `R`；再让帧级清晰度权重与帧级信噪比权重在指数上按 `R` 线性插值融合——细节区吃清晰度，朦胧区吃信噪比，同一幅成品里两头兼得（论文摘要、1.3 节）。

**融合式（论文式 6）**：

```
W[i,r] = C_i^(A·R_r) · S_i^(B·(1−R_r))
```

**逐像素归一（论文式 7）**：对每个像素除以该像素的权重均值，使权重均值为 1、总和为 N：

```
W̃[i,r] = W[i,r] / ( (1/N) · Σ_j W[j,r] )        Σ_i W̃[i,r] = N
```

归一保证加权平均不改变总曝光量，成品背景水平与等权叠加一致；权重只有相对意义，与帧数无关（3.3 节）。

### 1.1 三类权重

| 符号 | 含义 | 定义式 | 类型 |
|---|---|---|---|
| `C_i` | 帧清晰度权重 | `C_i = med_j FWHM_j / FWHM_i`（论文式 4） | 帧级标量 |
| `S_i` | 帧信噪比权重 | `S_i = med_j σ_j / σ_i`（论文式 5） | 帧级标量 |
| `R_r` | 分区权重场 | 论文式 8（见第 3 节） | 逐像素连续场，∈[0,1] |
| `σ_i` | 帧噪声尺度 | `σ_i = 1.4826 · MAD_r(D[i,r] − median_r D[i,r])`（论文式 3） | 帧级标量 |

- `C_i > 1` 表示该帧比全批中位更锐，`C_i < 1` 表示更糊。所有帧在**同一批固定星点位置**上测量（固定星表，见 3.5 节），故帧间严格可比。
- `S_i > 1` 表示该帧噪声低于全批中位。常数 1.4826 使 MAD 对高斯噪声无偏；MAD 对星点与目标结构不敏感，适合以天空背景为主的帧。
- `R_r = 1` 表示该像素属**细节型**（星核、旋臂、亮丝），`R_r = 0` 表示**朦胧型**（天空、无结构弥漫背景）；二者之间是连续过渡，不存在硬边界。

### 1.2 三个端点的行为（论文式 6 的性质）

- **`R_r = 1`（细节区）**：`W̃[i,r] ∝ C_i^A`，权重只由清晰度决定。糊帧（`C_i < 1`）被压为 `C_i^A`，A 较大时被强烈抑制，细节区由锐帧主导。
- **`R_r = 0`（朦胧区）**：`W̃[i,r] ∝ S_i^B`，权重只由信噪比决定；由 B = 2 的逆方差最优性（第 2 节），该区严格退化为逆方差加权 `∝ 1/σ_i²`。
- **中间区域**：指数 `A·R_r` 与 `B·(1−R_r)` 随 `R_r` 线性插值，故 W 随 R **连续变化**，不存在台阶与拼接痕迹。

实测分区场分布：`R < 0.1` 的像素占全画面 84%～87%，`R > 0.5` 的像素仅占 **0.17%～0.32%**，`R > 0.9` 几乎不存在。即绝大多数像素的权重几乎完全由 `S^B` 决定，这是本方法不牺牲信噪比的结构性原因（3.4.2 节、6.1 节）。

## 2 A/B 标定依据（本节最重要）

### 2.1 B = 2 不是标定出来的，是推导出来的

论文 3.3 节的完整推导（逐字复现其逻辑）：

1. 设各帧为**同一真值的无偏估计**且**相互独立**。
2. 加权平均 `μ̂ = Σ_i w̃_i D_i`，约束 `Σ_i w̃_i = 1`。
3. 其方差为 `Var(μ̂) = Σ_i w̃_i² σ_i²`。
4. 在约束下最小化该方差（拉格朗日乘子），得 **`w̃_i ∝ 1/σ_i²`**——即逆方差加权；此时 `Var(μ̂) = 1 / Σ_i σ_i^(−2)`。
5. 由论文式 5 有 `S_i ∝ 1/σ_i`，故 **`S_i² ∝ 1/σ_i²`**。
6. 因此 **B = 2 时，朦胧区权重恰为逆方差最优解**。

**结论：B 不需要标定。除实验外不应修改。** 论文表 2 把 B 的状态明确标为「理论值（3.3 节），不标定」。引擎命令行参数说明同样写「B=2 由逆方差最优性给出……除实验外不建议修改」。

### 2.2 A 是唯一需要经验标定的参数

- **默认 A = 20**（论文表 2，状态标为「**唯一需标定**」）。
- 在 `R = 1` 处权重为 `C_i^A`。**A 控制细节区里「用多少信噪比换多少解析力」**：A 越大，幂次加权把权重压向最锐帧越强；A 越小，越接近等权。
- 论文的验证只用了**一组**参数：`A = 20`、`B = 2`、`κ = 3.5`、亮度归一包络映射，横跨八个差异极大的数据集（NGC 7331 L/R/G/B、M81、NGC 6888 Hα、M15、LBN576 OIII；32～166 帧；120～900 s 混曝；宽带与窄带；五个目标、四类形态）。

**论文 6.1 节 / 表 4 的核心数字**：

- 成品星点 FWHM 相对单帧中位改善 **3.7%～43.8%**，且**改善幅度与帧间真实清晰度离散度同步**：
  - NGC 6888（`C_i` 跨 **2.81×**，离散最大）改善 **43.8%**（7.57 px → 4.26 px）；
  - M81（`C_i` 跨 **1.35×**，帧间几乎同样锐）只改善 **3.7%**（1.96 px → 1.89 px）。
  - 解读：清晰度加权能兑现的正是数据里真实存在的质量差异；没有差异可利用时它自动退化为逆方差加权，不劣化结果。
- **信噪比代价被结构性地限制住**：以「无分区基线」（A 置 0、保留 `S^B` 逆方差加权，论文 5.2 节）为参照做全幅消融，天空背景相对噪声仅上升 **1.4%**（NGC 7331 L，6.31e−5 对 6.22e−5）与 **3.1%**（NGC 6888 H，4.54e−5 对 4.40e−5）。
- 原因：分区场只覆盖 **0.17%～0.32%** 的像素（`R > 0.5`）；朦胧区 `N_eff` 中位几乎不变（128.6 对 128.9、22.8 对 23.5），`N_eff` 下降集中在细节区（38.7 对 160.6、4.9 对 30.6）。

### 2.3 A 的调节方向

| 方向 | 后果 |
|---|---|
| **A 调小** | 天空噪声增长更少（更保守）；星点略软；细节区等效帧数更高 |
| **A 调大** | 星点更细、解析力更强；天空噪声上升；细节区 `N_eff` 下降（该区实际由更少的锐帧决定） |

论文 6.1 节要点 4 强调：细节区 `N_eff` 的下限（32 帧的 NGC 6888 仅 4.9）是「解析力与信噪比的**物理权衡**，不是参数选择失误」。

**必须向用户明说的一点**：论文的八数据集验证共用**同一个 A**，因此 **A = 20 是经过验证的通用工作点，不是针对某个目标的拟合值**。换目标无需重新标定 A（这是与「基于绝对对比度阈值的映射」的根本区别，见 3.4 节）。只有当数据本身远离验证范围（采样率差异极大、帧数远低于 20、星点极暗）时，才需要连同其他参数一并复核（论文 4.2 节、7.4 节）。

## 3 分区场 R 的构造（论文式 8）

### 3.1 参考像

取全批中最锐的 `k` 帧的**等权中位**作为参考像 `S_ref`。用中位而非平均可抑制个别帧的残余离群结构；只取最锐的若干帧是为了让参考像的结构信息尽量少受模糊污染。**默认 k = 8**（用户可设），是稳健性与计算量的折中。因为 R 取的是参考像的**亮度归一**包络，k 只改变参考像自身的锐度与噪声，不改变 R 的归一化形态，故这一参数不需要跨目标重设（3.4.1 节）。

### 3.2 包络公式

记参考像的天空水平 `μ = median(S_ref)`、噪声尺度 `σ = 1.4826·MAD(S_ref)`、正信号 `d = max(S_ref − μ, 0)`：

```
R_r = clip( d_r / (M_r + ε·σ), 0, 1 )^η
M_r = max_win d                       （以 r 为中心、边长 2h+1 的方形窗口内的局部极大值）
win = 2h + 1,   h = max(1, round(2·σ_psf))
```

参数与默认值：

| 参数 | 默认 | 含义 |
|---|---|---|
| `h` | `max(1, round(2·σ_psf))` | 半边宽 ≈ 2·σ_psf，故 **win ≈ 4·σ_psf**；下限 h ≥ 1 即窗宽 ≥ 3 px |
| `ε` | 8 | 天空抑制常数（×σ） |
| `η` | 1 | 形状幂；η < 1 更宽松、η > 1 更紧 |

`σ_psf = med_i FWHM_i / 2.3548`（高斯 FWHM = 2√(2 ln2)·σ），取自引擎所用固定星表（3.5 节）。论文数据集的 `σ_psf` 为 0.85～3.14 px，对应窗宽 5～13 px。

### 3.3 为什么径向轮廓里没有星点亮度（论文式 9、10）

设单颗孤立星点在参考像上的剖面为 `I(r) = I_0·exp(−r²/(2·σ_ref²))`。当 `r ≤ h` 时窗口仍含峰值，`M_r = I_0`：

```
R(r) = I(r)/I_0 = exp( −r² / (2·σ_ref²) )                     r ≤ h        （论文式 9）
```

当 `r > h` 时窗口内离峰最近的点落在 `r − h` 处，`M_r = I(r − h)`：

```
R(r) = I(r)/I(r−h) = exp( −(2rh − h²) / (2·σ_ref²) )          r > h        （论文式 10）
```

两段的自变量**只有 `r/σ_ref` 与 `h/σ_ref`，不含 `I_0`**；而 h 与 σ_ref 都由该数据集自身测出。因此亮星与暗星、亮目标与暗目标得到**同一条归一化径向曲线**——这就是该映射被称为「尺度自由」的原因，也是它**跨目标通用、换目标无需重新标定**的根据（3.4.2 节）。

注意 `σ_ref` 与 `σ_psf` 的差别：`σ_psf` 按全批 FWHM 中位定义，而 `S_ref` 是最锐 8 帧的中位，其自身尺度 `σ_ref` 更窄；二者之比即帧间质量离散度 `ρ = σ_psf/σ_ref`，论文实测 `ρ ∈ [1.19, 1.93]`（7.2 节）。实测径向轮廓（NGC 7331 L 与 NGC 6888 各 60 颗亮孤立星）：**半高半径约 0.4～0.5 σ_psf，到 2σ_psf 处已降至 0.04～0.07、与天空底座齐平**。

### 3.4 天空与朦胧区的行为（ε 的非经验着落点）

窗内约含 `win² ≈ 25～169` 个近似独立噪声样本，其极大期望约 `σ·√(2 ln win²) ≈ 2.5～3.2 σ`；`d` 作为噪声正半部均值为 `σ/√(2π) ≈ 0.40σ`。于是天空区的典型分区权重为：

```
R_sky ≈ 0.40/(2.5 + ε) ~ 0.40/(3.2 + ε)
```

ε = 8 给出 `R_sky ≈ 0.036～0.038`，与实测星周外环底座（0.035～0.037）及各数据集分区场均值 `R̄ = 0.038～0.043` 吻合。

对平滑亮星云区 `M_r ≈ d_r`，故 `R ≈ d_r/(d_r + ε·σ)`：**只有当该处信号显著高于 ε·σ 时才有 R ≈ 1**。这不是缺陷——那里 R 在空间上近似常数，`R' ≈ 0`，不产生星周伪影，代价仅是局部 `N_eff` 下降。反之，若延展结构本身暗弱、`d` 与 `ε·σ` 同量级，则该区仍按朦胧型处理、只吃信噪比。NGC 6888 大体属于后一种情形（其丝状结构局部对比度只比天空起伏高约 50%），故全图仅 0.32% 的像素 `R > 0.5`。

## 4 帧级归一（论文式 1、2）

### 4.1 曝光归一必须先做（论文式 1）

```
D[i,r] ← D[i,r] · (t_0 / t_i)                                  （论文式 1）
```

线性数据下信号正比于曝光时间、噪声正比于其平方根。归一后所有帧等价于同一曝光时长，各帧噪声尺度 `σ_i` 可直接跨帧比较——**这是信噪比权重 S_i 成立的前提**。NGC 7331、M15、M81 均为混曝数据集（论文 5.1 节）：未归一时 `σ_i` 同时含有曝光时长与真实噪声两种信息，`S_i` 便失去意义。故这是**必需步骤而非可选步骤**。

### 4.2 天空加性平移（论文式 2）

以天空水平最接近全批中位的那一帧为锚，逐帧减去常数：

```
D[i,r] ← D[i,r] − (b_i − b_anchor),     b_i = median_r D[i,r]     （论文式 2）
```

`b_0` 即式 2 锚帧平移后的公共天空水平。该校正为加性、逐帧常数，不引入任何空间结构。

**为什么对本方法特别必需**：由于权重随位置变化，若各帧天空水平不一致，则 `Σ_i w[i,r]·b_i` 会随 r 变化，把帧间天空差异**印到画面结构上**，在分区过渡处形成**可见的亮度台阶**（论文 3.2 节）。这是 PWS 特有的强制要求——经典等权叠加里 w 与 r 无关，同一常数项不产生空间结构；而 PWS 里权重是位置的函数，任何未消除的帧间天空差都会乘以一个随位置变化的权重，从而显形。

### 4.3 帧噪声尺度（论文式 3）

```
σ_i = 1.4826 · MAD_r( D[i,r] − median_r D[i,r] )               （论文式 3）
```

## 5 排异（论文式 11）

最终叠加为**单次**加权平均，排异内嵌其中。排异只对**单个像素上的跨帧取值**做资格审查，其对象是宇宙线、热像元、卫星轨迹这类探测器级伪迹——它们的偏差是探测器级的绝对量，与局部结构无关（3.6 节）。

### 5.1 判据

对每个像素 r，取跨帧**中位数**为锚 `a_r = med_i D[i,r]`（对「多帧伪迹汇合在同一像素」免疫），跨帧偏差的稳健尺度为 `s_r = 1.4826·MAD_i(D[i,r] − a_r)`。帧 i 在该像素被排除，当：

```
| D[i,r] − a_r |  >  κ·s_r  +  m·R_r·max(a_r − b_0, 0)          （论文式 11）
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `κ` | 3.5 | 噪声阈值系数（以 σ 为单位，线性可感：越小越严） |
| `m` | **数据自测** | 排异信号容差，无需设置 |
| 少数派闸门 | 1/3 | 见 5.3 节 |

### 5.2 关键思想：细节区的帧间分歧是信号，不是伪迹

- **噪声项 `κ·s_r`**：天空与朦胧区（`R ≈ 0`）只有噪声分歧，式 11 退化为经典 κσ 截尾。
- **信号项 `m·R_r·(a_r − b_0)`**：细节区的帧间分歧**随局部信号增长**——各帧 PSF 不同的物理表现，锐帧与糊帧对同一星核的真实期望值本就不同，核值差可达 `(FWHM_med/FWHM_sharp)² − 1` 倍信号。若只有 `κ·s_r` 一段，星核的锐/糊连续谱会被成片误排、把星核排稀。信号项按局部信号放宽容差，把**真实结构整段豁免**，只排超出它的绝对量偏差——伪迹的偏差/信号远超真实分歧上界，两者在该判据下可分。

**容差系数 m 从数据里实测**（不靠经验设定）：在细节像素（`R > 0.5` 且 `a_r > b_0`）上对每帧计算 `|D[i,r] − a_r|/(a_r − b_0)`，取其 **99 分位**（伪迹只占极少数像素，动不了 P99），再**跨帧取中位**（个别帧的坏像素动不了跨帧中位）。m 即该数据集**真实分歧的上界**——天然包含视场梯度、混星与 PSF 形状误差等一切真实效应，换数据自动跟随。论文八个数据集未对 m 做任何设置。

### 5.3 少数派闸门（默认 1/3）

若某像素被标记的帧数过多，说明这不是孤立离群（典型情形：星核处锐帧与糊帧的双峰分布、图像边缘的配准黑边），**该像素不做排异**。

闸门按**扣除噪声期望误排后的超额数**判定：高斯噪声下 κσ 截尾的期望误排数为 `n·erfc(κ/√2)`，只有超出该期望的部分才计入闸门；超额数不超过 `gate·N`（默认 gate = 1/3）时才执行排异。期望修正使闸门与 κ 解耦——κ 较小时噪声尾的合法误排不会顶穿闸门、把真伪迹裹挟成「多数派」而漏网（3.6 节）。

### 5.4 结果

被标记的 (i,r) 权重置 0，随后重新归一，仍是同一次加权平均。排异掩膜只依赖帧数值、不依赖权重，故在权重均匀的像素上本方法的排异与常规无权排异结果完全一致。论文成品中被排异剔除的像素比例很低：**0.90%**（NGC 6888 H）、**1.22%**（NGC 7331 L）、**1.50%**（M15 L）。

## 6 适用范围与局限（论文 7.4 节与各前提）

诚实列出——这些是向用户解释「结果为什么不够好」时的第一手依据。

1. **帧预处理不在范围内。** 方法**假设输入已校准、已配准**。分区加权的正确性依赖帧间几何配准与天空一致性（论文式 2）。配准插值还会在同一输出位置引入跨帧噪声相关（见第 4 条）。引擎不修改、模糊或重采样任何单帧。
2. **依赖星点测量。** 清晰度权重 `C_i` 以星点 FWHM 为依据。固定星表的建立（论文 3.5 节）：在 `S_i` 最大（最干净）的帧上检测；剔除饱和星（峰值超过该帧最大值 80%）与边缘星（距边界小于 26 px）；剔除相互距离小于 25 px 的星（保证拟合窗口内无混星）；按峰值降序取前 `N_star = 120` 颗。每帧在同一批位置上做高斯轮廓拟合（窗口 33×33，局部天空按外环 r ∈ [13,16] px 扣除，拟合区 29×29，初值 FWHM = 6 px），取拟合成功星点的中位作为该帧 `FWHM_i`。若视场内缺乏足够亮星（例如窄带极暗场或纯星云特写），**需改用其他帧级清晰度判据**。这不影响分区机制本身。
3. **采样率。** 星点测量窗（33×33 拟合窗、29×29 拟合区、外环 r ∈ [13,16] px）是**绝对像素值，不随 σ_psf 缩放**；包络窗宽 `2h+1` 虽随 σ_psf 变化，但 σ_psf 很小时取整误差占比变大。论文 `σ_psf` 最小的 M81（0.85 px，单帧 FWHM 中位 1.96 px）窗宽仅 5 px，已处临界采样，其成品 FWHM 改善仅 3.7%（八者最小）——其中多少来自「帧间本就同样锐」（`C_i` 仅跨 1.35×）、多少来自欠采样，论文未分离。**迁移到采样率差异更大的数据时应重设这些窗尺寸。**
4. **B = 2 的最优性有前提，且在结构像素上不成立。** 3.3 节的推导要求各帧**对同一真值无偏**、且**帧间噪声相互独立**：
   - 第一条在结构像素上并不满足——各帧因视宁度不同而具有不同 PSF，糊帧在该像素的真实期望值本就更低，那里不存在「同一真值」（论文 7.1 节把输出写成两种有效 PSF 的混合，正是这一点的体现）。
   - 第二条也可能被破坏：配准插值会在同一输出位置引入跨帧相关；未除净的固定图案（暗电流结构、平场残差）是**系统误差而非噪声**，逆方差加权对它无效。
   - 因此「朦胧区退化为逆方差加权故信噪比最优」这一表述，严格说只在**天空主导、帧间噪声近似独立**的像素上成立。
5. **需要足够帧数。** 论文**建议总帧数 N ≳ 20 时启用本方法**（3.4.1 节）。帧数为个位数时，可用的清晰度差异本就有限，清晰度加权的收益随之下降，经典加权平均已足够。该阈值为经验建议，实际取决于单帧质量的离散程度。32 帧的 NGC 6888 细节区 `N_eff` 仅 4.9，该区噪声显著高于天空区，是数据量本身的物理极限。
6. **画面结构占比低时收益有限。** `R > 0.5` 仅占 0.17%～0.32% 的像素，主要收益集中在星点与结构核心；大面积极暗弱背景仍需长曝光堆积。
7. **细节区只取正向偏离，不覆盖负对比结构。** R 由「高于天光」的正向偏离构造，故 `R > 0.5` 只圈定亮对比结构（旋臂、亮丝、星核）；暗星云通道这类**负对比**结构不进入细节区（LBN576 即此例）。这是权重的有意取舍——负对比区应判为朦胧型、只吃信噪比。
8. **分区特有的伪影：星周亮度平台（目视表现为「亮—暗—亮」伪影环）。** 其解析成因见 7.1 节：输出剖面是两种有效 PSF（锐帧加权与全帧平均）随半径变化混合的结果，混合比的径向导数 `R'(r)` 与两者之差 `ΔPSF(r)` 相乘产生额外项 `−(dR/dr)·[PSF_mean(r) − PSF_sharp(r)]`；在星翼处 `dR/dr < 0` 而 `PSF_mean > PSF_sharp`，该额外项为正，抵消自然衰减，剖面「变平」。**亮度归一包络映射正是为消除它而设计**（论文 6.4 节：成品剖面的逐半径对数降幅与无分区基线同水平，平台被消除而非仅减弱；`ν(r_bright) = 1.05`，阈值 1.10）。三条独立约束指向同一设计准则：**分区过渡必须在约 2σ_psf 内完成，且其位置必须由 σ_psf 定义而非由绝对对比度阈值定义**（7.2 节）。相应地，**伪影判定窗口必须按 σ_psf 归一**——论文最终以 `[3.8, 4.8]·σ_psf` 作为标准化判定窗（平台实测落在约 4σ_psf：NGC 7331 为 3.9～4.7 σ_psf，NGC 6888 为 4.2～4.7 σ_psf）。若把判定窗口固定为像素值（例如 r ∈ [8,11.5] px），对 σ_psf = 2.27 的 7331 相当于 3.5～5.1 σ_psf（正好覆盖平台），而对 σ_psf = 3.14 的 6888 只相当于 2.5～3.7 σ_psf（几乎错过平台），跨目标失真。
   - 平台伪影的幅度由 `|dR/dr|·|ΔPSF|` 决定。**把过渡摊宽并不能解决问题**，因为它同时把过渡推到 `r > r_c` 更远处，那里 `|ΔPSF|` 更大；正确做法是把过渡向内侧移到交越半径 `r_c` 附近（`r_c/σ_psf = 2√(ln ρ/(ρ²−1))`，论文式 20；`ρ ∈ [1.19,1.93]` 对应 `r_c/σ_psf ∈ [0.98,1.29]`，即约 1σ_psf 量级，近似普适）。
   - 另一个必须知道的点：该剖面在数学上**始终单调**（没有局部极值），只是斜率在某半径区间变小，因此任何以「寻找局部极大/极小」为基础的自动判据都检测不到它，而人眼对斜率变化非常敏感（7.1 节）。
   - 权衡的诚实说明：亮度归一包络的过渡从星心就开始下降（实测 R 在 1σ_psf 处已降到 0.15～0.29），故中等半径处的清晰度加权略弱于对数斜坡映射，代价是成品星点略软。**要更强的锐化，就必须接受更深的伪影环**——二者由同一个 `|dR/dr|·|ΔPSF|` 项绑定（7.2 节）。
9. **已知的对照分层（不是局限，但须如实告知用户）**：改用「能量集中」的度量（半光半径 `r_50` 与 r ≤ 3 px 的包围能量），挑帧叠加在五个目标上全面占优（`r_50` 小 3.9%～8.6%、EE 高 0.6%～8.3%）。这两个量覆盖 `r ≲ 4` px 环带，恰是分区过渡带所在。以单一尺度下结论都不完整，故论文两组数字同时给出（6.3 节）。

**成品输出**（论文 4.1 节）：成品为线性态浮点灰度图，全程只有线性运算（曝光归一常数、量纲回乘常数、天空加性平移、加权平均），不做任何拉伸、归一或截断；文件头记录总曝光与参与叠加的帧数。成品导出前乘回 `t_med/t_0`（`t_med` 为素材曝光中位数），量纲与素材一致。随成品一并输出的诊断量有三个：**逐帧权重表**（帧号、FWHM、`C_i`、`σ_i`、`S_i`）、**分区场 R**、**等效帧数 N_eff**——agent 向用户解释结果时应优先读这三样。

**两个诊断判据**（论文式 14、15，用于确认本方法未引入噪声台阶）：

```
ν_r = √(N/N_eff,r) / med_r √(N/N_eff,r)                        （论文式 14）
ν(r_bright) ≤ 1.10                                             （论文式 15）
```

`ν_r` 的含义是「该处噪声相对全图典型水平被放大的倍数」。清晰度加权会使星周 `ν > 1`；**若 ν 直到星光滑入背景之后才回到 1，则噪声台阶落在纯背景上，拉伸后表现为肉眼可见的噪声环**。论文实测：在 `r_bright` 处本文映射 `ν = 1.05`（7331、6888 一致），无分区基线为 1.01。注意 `N_eff < N` 并不等于噪声更差——在逆方差权重下 `Var(μ̂) = 1/Σσ_i⁻²` 是所有线性无偏组合中最小的，`N_eff` 只是权重集中度的度量，而非噪声的直接读数（3.7 节注）。
