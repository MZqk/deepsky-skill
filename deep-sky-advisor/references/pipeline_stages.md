# 处理阶段参考

软件无关的阶段定义。用于理解报告里每个操作**处在哪个阶段**、进入该阶段的前置条件，
以及阶段级的完成与回退判据。

本文只讲**阶段**，不重复任何操作内容。相关来源：

- 每软件的工具、步骤、参数依据、蒙版策略 → `scripts/software_guidance.py`
- 每操作的目的、起始、调整、验收、回退 → `scripts/generate_advice.py`
- 决策状态、证据要求、阶段归属规则、双轨与交接契约 → `references/recommendation_policy.md`
- 各软件的菜单路径与特有事项 → `references/siril_workflow.md` 等三份扩展阅读

## 阶段模型

| 阶段 | 做什么 | Siril | PixInsight | Photoshop |
|---|---|---|---|---|
| `linear` | 校准、注册、叠加、裁切、背景建模、测光校色、窄带映射、线性降噪、星形诊断 | 是 | 是 | **否** |
| `nonlinear` | 受控拉伸、高光保护、星点处理 | 是 | 是 | 仅收尾微调 |
| `finishing` | 主轨产出之后的精修 | 可选 | 可选 | 是 |
| `export` | 母版保存与交付导出 | 是 | 是 | 是 |

## `linear`

**含义**：数据仍为线性，像素值与光子数成正比。这是唯一能做「测量类」操作的阶段。

**包含操作**：`calibrate_integrate`、`crop_edges`、`background_review`、`color_calibration`、
`narrowband_mapping`、`linear_denoise`、`star_shape_review`

**进入条件**：`classification.transfer_state` 表明数据仍为线性。若文件已经拉伸，
**不得**按线性阶段推荐这些操作。

**阶段级完成判据**：

- 校准帧与亮场匹配，拒绝图里是伪影而不是真实信号；
- 无效注册边缘已清除；
- 背景模型经审查后确认不含天体结构，或已决定不做；
- 宽带数据完成测光校色，或窄带数据完成并记录了通道映射；
- 线性降噪后暗弱小星与连贯细丝仍在。

**阶段级回退迹象**：

- 校准或拒绝删除了真实星点/目标结构；
- 背景校正后出现黑坑、色彩断层或角落过减；
- 降噪后小星消失、细丝断裂、尘埃变塑料感；
- 校色后彩色恒星被洗白、通道被裁切。

**为什么不能放到下游**：这些操作依赖线性响应关系。在已拉伸的数据上做背景建模、
测光校色或线性降噪，得到的结果没有物理意义。这正是 Photoshop 不拥有 `linear` 阶段的原因。

## `nonlinear`

**含义**：已完成非线性拉伸，像素值不再与光子数成正比。此后只能做「显示类」操作。

**包含操作**：`controlled_stretch`、`highlight_protection`、`star_treatment`

**进入条件**：linear 阶段的关键步骤已完成，尤其是背景与校色。否则拉伸会把尚未处理的
背景与色偏一起放大。

**阶段级完成判据**：

- 背景与纯黑分离且没有硬截断；
- 亮核保留内部层次，星色仍可见；
- 星点层级、颜色与小星数量保持自然，或按目标类型显式保留。

**阶段级回退迹象**：

- 黑位裁切增加、亮核变死白、星点明显膨胀；
- 保护区变灰或出现硬 HDR 边界；
- 星点变得大小一致且人工化。

## `finishing`

**含义**：主轨产出已经成型之后的精修。它**不是**必经阶段，只有在测得具体问题时才执行。

**当前实现**：`color_refinement`（处理已测得的残余色偏）。本阶段还为局部对比与
输出级降噪锐化预留，尚未实现。

**进入条件**：存在**可测量**的残余问题，且该问题无法在主轨更早的阶段解决。

**阶段级完成判据**：

- 未饱和恒星颜色合理；
- 背景没有出现彩色噪声斑块；
- 没有通道被进一步推向上限。

**阶段级回退迹象**：

- 背景出现彩色斑块、恒星被染色；
- 通道裁切增加；
- 真实发射颜色被中和。

**注意**：没有可测问题时，本阶段的操作应判定为 `skip`。提升饱和度或局部对比属于审美
选择，不是诊断结论。

## `export`

**含义**：保留处理余量，并产出颜色可预测的交付副本。

**包含操作**：`final_export`

**阶段级完成判据**：

- 高位深母版完整保留；
- 交付副本嵌入配置文件，没有新增色带、裁切或锐化光晕。

**阶段级回退迹象**：

- 导出后颜色异常、出现色带；
- 暗部或高光被裁切。

## 交接点

1. **linear → nonlinear**：背景与校色完成之后才拉伸。拉伸是单向的，
   它会把尚未处理的背景与色偏一起放大。
2. **主轨 → finishing**：主轨的 `export` 产出 16-bit TIFF 后交给 Photoshop。
   交接要求（位深、色彩空间、已完成项、不可逆项）由报告的「交接给 Photoshop 的契约」一节给出。
3. **主轨之间**：Siril 与 PixInsight 是**并列备选**，不是串联管线。任选其一执行；
   不要对同一目标叠加两条轨的同类操作。

## 为什么边界重要

- 在错误的阶段做操作会得到没有物理意义的结果：在线性数据上用显示域工具，
  或在非线性数据上做测光校色。
- 把 `linear` 工作交给 Photoshop 会诱导使用像素级修补工具，从而伪造天体信号。
- 把审美操作当作诊断结论，会稀释「有证据才建议」的纪律。
