## 安装 SkillDeck 到 WorkBuddy
- 形态：独立 web 版（非 MCP；MCP 版用 `@modelcontextprotocol/ext-apps` 的 Codex widget，WorkBuddy 不支持）。
- 源码位置：`/Users/mz/dev/skills/skilldeck/`，零依赖（`server.js` 只用了 Node 内置模块），无需 npm install。
- 安装方式：在 `~/.workbuddy/skills/skilldeck/SKILL.md` 建用户级 skill，指导启动 `node server.js` 并把来源默认指向 `~/.workbuddy/skills`。
- 已把 `/Users/mz/.workbuddy/skills` 写进 `/Users/mz/dev/skills/skilldeck/.skilldeck.state.json` 的 recentDirs，开箱即在卡片墙侧栏显示（标签 `workbuddy/skills`，15 个 skill）。
- 启动命令：`SKILLS_DIR=/Users/mz/.workbuddy/skills <node22> /Users/mz/dev/skills/skilldeck/server.js`，监听 `http://localhost:4177`。
- 注意：「本地运行」按钮依赖本机 codex/qodercli，通常没装，用「复制口令」即可。
