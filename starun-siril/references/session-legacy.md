## Neutral held-out benefit and paired safety

Current sessions freeze `neutral=scientific_native_flow_v2`. A neutral declaration
binds an explicit `background_partition` (at least three fit and three validation
sky regions) without changing regions.v1. Only fit regions estimate coefficients.
The immutable run receipt carries `processing_checks.color_calibration.neutral_validation`
(`starun-siril.neutral-validation.v1`): held-out RGB-median ranges, paired endpoint
transitions, fixed subject/stellar signals, spatial coverage and input fingerprints.
Scientific float endpoints are risks, not proof of hard clipping. Numerical results
remain uncertain; no new benefit/safety rejection threshold or visual acceptance is
introduced. Bound neutral evidence avoids rejection based solely on inherited total
shadow counts. Generic gates for other methods remain unchanged.

Neutral review binds the receipt and region contract; accept requires actual parent
and candidate image materials and all applicable visual gates. Optional metrics and
recovery reference this evidence; reporting failures retain the scientific receipt.
Old policy receipts are not rewritten or backfilled; initialize a new session for
new execution. See [color calibration](stages/stage-04-astrometry-color.md#color-calibrate) for the contract.
