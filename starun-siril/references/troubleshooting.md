# Artifact Troubleshooting Reference

用于质量审查发现伪影、偏色或结果退化时。只处理单个已堆栈 master 的后期排查；上游采集、校准、
去拜耳和堆栈问题只记录证据与所需检查，不在当前合同内重新处理序列。

## 证据与最小恢复

1. 分开记录可见问题、可能原因和确认测试。JPEG/PNG 或截图不能证明原始校准质量、位深、Bayer
   正确性或线性源裁剪；线性状态与通道来源仍遵循 session 合同，未知时停止推进。
2. 对照原 master、最后一个已接受父源与问题候选，定位伪影首次出现的阶段。使用相同显示传递、
   缩放与固定区域比较；linked-autostretch 参数相同仍可能随图像统计变化，不能单独证明背景改善。
3. 输入已有问题时，先查 FITS Header、采集/校准记录或向用户索取关键证据；不靠更强背景扣除、
   降噪或绿色抑制掩盖上游错误。原因未证实就保留为假设。
4. 本阶段新增问题时，reject 候选并保留已接受父源；只有存在具体可修正原因时才以新编号生成
   最小修订，仍逐协议运行、审查。验证结果不支持假设或证据不足时停止，不反复试参数。

观察、假设、检查材料和结论写入现有 review notes；实际用于 SSF 参数选择时将本页绑定为
supporting reference，不新增协议、receipt 字段或质量门，也不改写旧 session/receipt。

## 常见症状

表中原因均为待验证假设；同一症状可能同时有上游与后期原因。先定位首次出现阶段，再选对应检查。

| 可见问题 | 可能原因 | 最小确认与处理边界 |
|---|---|---|
| 大尺度梯度、背景坑洞或微弱尘埃变淡 | 月光/光污染、结露；背景样点包含目标/星晕/尘埃，模型过拟合 | 对照输入与背景候选的固定区域及样点合同；坑洞仅在扣背景后出现时 reject，优先纠正样点或降低模型复杂度。完整处理即使目标铺满画面也须先提议并审查控制区，允许一次人工修订；仍无可信天空才记录证据并保留父源，禁止缩小主体保护。 |
| 尘斑残留、尘斑反相或四角过亮 | 平场不匹配、过曝；bias/dark-flat 策略不兼容；滤镜/焦点/相机角度或尘埃改变 | 核对平场与光帧来源、平场裁剪及实际校准顺序，不能仅看 master 确诊。输入已有反相尘斑不靠背景模型消除，所需上游重校准在本合同外。 |
| 斜向行走噪声 | 抖动不足、固定图样残差、堆栈拒绝不足 | 对照线性 master 与拉伸候选，查抖动和堆栈记录。拉伸可能只是显露已有噪声；当前技能不能补采样或重做堆栈拒绝。 |
| 水平/垂直条纹 | 传感器固定图样、校准残差、拉伸/局部增强放大 | 在相同区域逐阶段比较，并查增益、温度及校准记录。条纹不是普通随机噪声；不反复加大降噪直到背景被抹平。 |
| 棋盘格、彩色细格或去拜耳异常 | CFA 模式/行序/偏移不匹配、重复去拜耳；也可能是分星新增格纹 | 核对上游原始 Header 的 BAYERPAT、ROWORDER、XBAYROFF/YBAYROFF 与去拜耳记录，确认首次出现阶段。master 的残留关键字不足以证明像素仍为 CFA；不重新去拜耳已堆栈 RGB。 |
| 绿色偏色、洋红星点或色块 | 校色失败、通道角色/滤镜响应不匹配、窄带映射、过饱和或通道信噪比差异 | 核对通道来源及校色/映射 receipt，并比较各阶段星核与背景。按 [color.calibrate](stages/stage-04-astrometry-color.md#color-calibrate)、[color.map](stages/stage-08-starless-enhance.md#color-map) 和 [color.finish](shared-protocols/color-finish.md#color-finish) 验证；不以 rmgreen 代替校色或消除有效窄带信号。 |
| 大星光晕或彩边 | 输入滤镜/光学光晕、色差、增强过强、分星/合星放大 | 比较输入与候选中同一星的核心和晕环。输入已存在的光晕不能仅凭后期图确定滤镜或光学原因；后期新增则回到引入问题前的父源。 |
| 星旁明暗环、振铃或过锐边缘 | PSF 不适配、反卷积/局部增强过强 | 对照反卷积父源、PSF、星表与候选，既看星点也看目标边缘。按 [restoration.deconvolve](stages/stage-05-linear-restoration.md#restoration-deconvolve) 验证，不仅凭 FWHM 下降采用候选，也不以降噪掩盖振铃。 |
| Starless 残星、黑洞、格纹，或星层出现星云/星系结构 | 分星残留、目标泄漏、模型对当前数据不适配 | 检查同一分支的 full/starless/star layer，按下节区分残留与泄漏；异常或不确定则拒绝分星，保留含星父源，不在破损 starless 上继续增强。 |
| 双星、重复星、星边错位或合星后星径异常 | 输入配准问题；合星分支/几何不一致或显示传递链不匹配 | 输入已有双星时查参考帧、配准记录与离群帧；仅合星后出现时核对 branch、尺寸/方向及完整 transfer chain。前者需上游重配准，后者按 [stars.recompose](stages/stage-09-stars-recompose.md#stars-recompose) 回退，不能只降低星点强度掩盖错位。 |
| 星点膨胀、边角拉长或形状随视场变化 | 对焦/视宁度/导星、光学像差或倾斜、拉伸过强 | 对照中心/四角相同星区及可用 FWHM/roundness。新增长大先检查拉伸；输入已有形状问题需采集证据，不能仅凭后期图确诊硬件或以锐化伪造恢复。 |
| 卫星轨迹、短线段或堆栈异常残迹 | 帧数/拒绝策略不足、异常帧、轨迹在堆栈中未被排除 | 检查 master 中残迹，并在用户已有子帧、拒绝图和堆栈日志中核对相同位置；无材料就保留假设。当前合同不重做序列拒绝，也不把后期抹除当作科学恢复。 |
| 黑位截断或星核饱和 | 输入已裁剪/饱和，或后期黑点/拉伸/饱和度过强 | 比较科学 FITS 与上一父源的逐通道裁剪指标及实际像素；JPEG 统计只作显示诊断。候选新增裁剪则 reject；输入已丢失的星核/暗部信息不能靠后期恢复。 |
| 塑料感、噪声团块、目标纹理消失或伪结构 | 降噪、局部对比或背景模型过强 | 对照相同传递下的父源与候选，重点检查低信噪比目标边缘与固定背景区。更低全局噪声不等于更好；不能确认纹理保留就拒绝候选，不以锐化补回抹掉的结构。 |

## 分星与合星的定向检查

1. 在同一位置打开 full source、starless 和星层的真实材料，覆盖明亮星、密集星区及目标边缘。
   starless 中的残星/黑洞与星层中的目标纹理分别记录；星层包含星晕本身不等于目标泄漏。
2. 按 [stars.separate](stages/stage-06-stars-separation.md#stars-separate) 拒绝残留、格纹或目标泄漏。若所需材料已被清理，
   不能用文件名、旧摘要或 receipts 代替像素审查；报告缺失证据，不宣称定位成功。
3. 合星时对照完整含星显示基线、原始 starless 显示图、显示域星残差和最终候选。按
   [stars.recompose](stages/stage-09-stars-recompose.md#stars-recompose) 检查传递链与数值闭合；闭合通过仍须独立检查泄漏、
   重复结构、星径/星色及光晕。不得直接拉伸线性星残差或用裁剪/归一化隐藏负残差。

不能建立可信分星分支时保留含星路径。默认最终图仍须含星，未经用户选择不得改交无星图。

质量门及 accept/reject/uncertain 的含义仍以 [quality.md](quality.md) 为准。输入已有伪影也不豁免
最终质量门，不能仅写 limitation 就接受不合格输出。窄带绿色可能是信号或 palette 的有效部分，
不能把中性背景要求扩展成“主体必须无绿色”。
