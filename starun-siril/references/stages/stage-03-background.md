# Stage 3 · 背景梯度提取与光害分离

## 颜色保护证据

新 `color_preservation=vivid_preservation_v1` 会话在现有 `regions.v1` 中，用独立的 `faint`/`core` 区域声明实际可辨的弥散红色结构和蓝色反射结构。完整采样框必须避开保护区，不能只检查中心。逐区记录父源／候选的 RGB 中位数、亮度、最近有效独立天空扣除后的信号比例和端点变化。信号非正或没有可信且不与主体重叠的天空时，明确标记不可测；背景扣除按单位通道增益诊断保色。

审查新增 `color_protection_assessment`：在 `diffuse_red`、`reflection_blue` 下绑定实际区域 ID，或填写 `not_applicable_reason`；逐区说明连续性、颜色和弱外缘。标签只描述观察，不推断谱线来源。所有保护区均可接受才可采用；天空更中性不能抵消主体颜色损失。

完整处理中的每份线性输入必须完成本阶段的控制区提议、科学测量、局部审查和采样评估；只有满足下方[实测证据充分时跳过](#measured-evidence-skip)的条件，Agent 才可记录依据并保留父源、不运行背景候选。证据不足以支持跳过且控制区与样点合格时，仍须实际试跑。不得仅凭全幅预览“梯度不明显”或“未确认天空”直接跳过。采用候选仍须同源成功运行、独立控制验证及实际接受的审查；可信天空不足或候选无收益时保留父源，解码、来源或证据错误停止依赖处理。

仅在线性域评估背景扣除，且早于拉伸与非线性调色。unknown 输入先遵循输入门；已确认 nonlinear 不强行执行线性背景扣除。定向任务只执行用户请求的协议，定向背景处理沿用本页控制区、采样和审查要求。本阶段不补做平场，也不自动修复误减暗坑。背景中性化另在 Stage 4 评估。

本阶段维护专属协议正文、参数、SSF 与审查。按 [协议索引](../protocol-index.md) 绑定本文件为唯一 primary 和完整 SHA-256；实际参与决策的其他材料按原规则记录为 supporting。通用质量门见 [quality](../quality.md)。

<a id="stage3-required-assessment"></a>
## 完整处理必做评估

1. 从当前已接受线性科学父源调用现有 `siril_auto_samples.py --validation-regions`，按下方[来源规划](#background-subtract-v3-来源规划采样补救与精度)保存来源绑定的独立天空区提议与报告。实际打开全幅和控制区局部图，确认主体、外盘/外晕、尘埃及星晕保护范围，逐区记录采用或排除理由；均匀偏色不证明天空不存在。
2. 按下方[控制区资格与跳过依据](#background-control-eligibility)默认选择至少六个互不重叠、各至少 75×75 的可靠天空控制区，保持上中下各至少两个及既有空间跨度。初次不足时允许一次人工修订；有可信天空但完整布局仍不成立时，可在首次试跑前评估下方[受限一阶布局](#limited-plane-layout)，记录标准布局失败依据。两种布局均不成立时保留提议、局部审查和具体不足原因，保留父源继续。不能用“没有现成六区”替代实际提议与审查，不能缩小主体保护或控制区来凑数。
3. 控制区与 core/faint/stars 保护区域在评估跳过或执行候选前冻结为 `regions.v1`，再调用现有科学采样器并传入 `--exclude-regions`。实际检查完整 25×25 样框，按既有严格路径及一次稀疏紧凑星补救规则检查覆盖；需要人工修订时最多一次。真实天空或样点仍不足时记录具体不足；合格时继续完成下方源图实测与处置判断。
4. 完成源图实测和局部检查后，仅在[实测证据充分](#measured-evidence-skip)时可由 Agent 记录依据并跳过候选；否则控制区和样点合格时运行一个匹配当前证据的保守候选，即使全幅未显现明显梯度，也由独立控制区测量和配对预览判断收益。默认一次；仅在观察到具体可修正残差或采样问题时最多追加两次尝试。所有候选从同一科学父源开始，沿用冻结控制区；修订用新 run ID，在各自报告目录复制并重新绑定同内容的控制区，禁止连续叠加扣除或根据候选结果移动控制区。不要求遍历全部模型。
5. 在 `reports/stage-03-assessment.md` 按发生顺序记录来源路径/SHA-256、实际查看的材料及显示参数/局部坐标、区域选择与排除理由、保护范围、科学测量方法/原始结果及误差或限制、采样报告和实际点数/覆盖、模型及参数理由、实际调用及时间、run/review 引用与最终处置。实测支持跳过时明确记录“未运行背景候选”、支持结论的空间测量与局部观察及为何无需试跑，并区别于天空/采样不足和试跑后无收益。没有候选时也保留这份说明，不伪造 run/review 或候选收益；候选继续使用既有 SSF/provenance、run 和 review，阶段说明不替代机器证据。交付 review.notes 引用阶段说明并概括采用或保留父源的原因，不把“未尝试”写成“无梯度”。

候选无收益、reject 或 uncertain 均保留已接受父源继续；来源、解码、哈希或几何错误沿用阻断规则。阶段说明及实测充分跳过属于 Agent 规范；执行候选时仍须通过下方策略、布局与科学硬门。

<a id="background-control-eligibility"></a>
### 控制区资格与跳过依据

可靠天空是当前背景估计可用的工程区域，不要求从单张图证明完全不存在极弱发射。区分实际可辨的壳层、连续云气、尘埃与宽星晕，以及尚未证实的污染；不能只因 NGC 6888 等目标名称、全幅偏红或“可能有发射”将全部候选排除。没有可辨目标结构或宽星晕、科学块中位数稳定且空间覆盖合格的区域可进入保守试跑；这不证明物理纯天空，采用仍取决于独立控制区与主体保护审查。

75×75 控制区允许零散紧凑星点，需结合局部图和九个 25×25 科学块中位数的稳定性判断。提议报告的 `structure_fraction`、`compact_star_fraction` 与 `block_median_mad_max` 是排序及检查线索，不是自动接受或一票否决。`structure_fraction=0` 不证明无发射，存在星点也不自动证明背景估计失效。10% 紧凑污染门只属于下方 25×25 拟合样框的稀疏星补救，不套用于 75×75 控制区；明显亮星翼部、宽晕或连续结构仍应避开，不修改既有采样器阈值。

按现有 `stage-03-assessment.md` 逐区记录坐标、实际观察与排除原因。尚未确认的候选先核对上述科学块统计并完成允许的一次人工修订；不能把“尚未确认”改写成“工具判定天空不足”。可靠控制区成立后必须调用带保护区的科学拟合采样器，再依据严格覆盖、一次稀疏星补救及允许的人工修订决定能否执行模型。除满足下方实测跳过条件外，只有具体污染仍无法避开、测量后仍不能区分目标与背景，或采样覆盖仍不合格，才在候选前保留父源；记录实际停止环节。未执行候选不能写成无梯度或无收益。

保留父源只结束本阶段的该次背景估计，不认定整幅图不存在可用天空。背景模型主要评估空间变化；即使其无收益，常数通道偏移仍可能需要处理。Stage 4 须独立评估中性化，后续阶段也按各自父源与区域条件判断，不传播本阶段的跳过结论。

<a id="measured-evidence-skip"></a>
### 实测证据充分时跳过候选

跳过的是背景候选执行，控制区提议、科学测量、采样与局部检查仍必做。Agent 复用现有科学像素读取和 ROI 测量，绑定当前父源 SHA-256、尺寸、方向及冻结区域，保存各天空区的 RGB（单通道则该通道）科学统计、完整 25×25 块的稳定性（标准区九块，受限区至少四块），以及按下方独立验证的像素定义计算的亮度、`R-G`、`B-G` 空间变化。结合上中下及 X/Y 覆盖、区域汇总的不确定性和可辨梯度尺度，说明这些测量为何足以支持在当前精度和覆盖范围内不做空间扣除；单个 ROI 平稳、全幅均值或统一偏色不足以支持此结论。公共 metrics ROI 仍只接受 FITS；XISF 沿用内部科学读取的 Image 0、单位与方向合同，不用显示像素替代。

同时实际打开可辨微弱结构的显式显示下的全幅、天空控制区及弱云气、反射区、外盘/外晕局部，核对测量与空间观察一致、没有相反梯度迹象，并保留现有主体保护范围。仅“看起来平”、低于单像素噪声、提议报告的掩膜比例或因测量精度不足而未检出，都不能授权跳过；缺测量、误差/覆盖无法约束空间变化或局部观察有疑问时，控制区与样点合格就必须试跑一个保守候选。真实天空/采样仍不合格时沿用上述安全保留父源路径，来源或解码错误仍阻断。

是否跳过由 Agent 综合证据判断并写入阶段说明，不新增固定科学阈值或自动 skip 门，不把该决定解释为不存在物理梯度或已经验证候选无收益。Stage 4 的宽带校色与双窄带中性化仍各自独立评估。

<a id="limited-plane-layout"></a>
## 显式受限一阶布局

默认 `layout="standard"` 保留六个 75×75 验证区、三分区配额及十二个拟合样点。有可信天空但标准布局或采样评估在允许修订后仍不足时，Agent 可在首次试跑前显式选择 `limited_plane_v1`。只允许 `subsky 1 -existing`；二至四阶和 RBF 继续使用标准布局。不得根据候选结果改换验证区、缩小主体保护或将无法区分的云气改标天空。

受限布局至少三个互不重叠、各至少 50×50 的验证区，每区至少四个完整 25×25 块；至少六个拟合样点。两组分别保持横纵覆盖可用画幅 60%，取消上中下各两区／点的配额。以去掉 4% 留白后的可用画幅归一化 `[1,x,y]`，验证区中心和拟合点的设计矩阵均须满秩 3、条件数不超过 100。完整 25×25 样框、验证区外扩 25 px、主体保护、来源与端点保护不变。这些数量及条件数是工程约束，不是物理置信保证；仍没有合格天空或二维约束时保留父源。

源图提议可用现有采样器的 `--validation-regions --background-layout limited_plane_v1` 生成 50×50 候选，提议本身不能授权拟合。逐框审查并冻结区域后，拟合采样必须同时传入 `--background-layout limited_plane_v1 --exclude-regions /abs/session/reports/030-background/regions.json`，可显式指定 `--samples 6`；目标数不保证最终覆盖成立。Stage 4 的 `--regions` 不接受布局覆盖，原参数和分区保持。

在现有 `# background-validation:` JSON 中增加 `"layout":"limited_plane_v1","layout_reason":"Actual standard-layout failure, inspected sky evidence and coverage limits"`，仍保留 regions 与 sha256；受限理由必须非空，省略 layout 时为标准布局。阶段说明保留标准布局失败的测量／修订证据、可信天空依据及覆盖限制。报告与回执绑定布局、理由、验证区覆盖和拟合覆盖，静态验证、执行后复核及回放使用同一规则。背景 v5 不改变 regions.v1、样点合同或报告 schema。

## 形态保护与大尺度梯度识别

结合 [目标形态参考](../target-morphology-review.md) 确认真实天空与保护区域。

- **按实际天空证据选择背景模型**：
  - 城市光害、靠近地平线或不同天顶距引起的宏观渐变，在画幅上通常表现为大尺度单向倾斜（Tilted Plane）；
  - 近似单向线性梯度推荐一阶平面 (`polynomial-1` / `subsky 1 -existing`) 作为保守候选。模型 $z(x,y)=Ax+By+C$ 的零曲率只约束模型形状，不能证明其扣除的低频分量全部来自天空。
  - 大星系外晕、弥散云气和 IFN 也可包含近似线性分量；避开亮核不等于避开目标。一阶仍可能误减真实信号，四周外缘也不自动是真实天空。完成控制区提议、局部审查和允许的一次修订后仍无法可靠区分时，记录证据并保留父源。
  - 二阶、RBF 及三/四阶的选择见下方[模型](#background-subtract-模型)。已有独立天空证据支持时可直接选择匹配模型，不要求先执行一阶；沿用同一父源、冻结控制区及实际像素审查。
- **弥散发射星云与富暗星云天区 (如 M8 礁湖星云、M20 三裂星云、M42)**：
  - **风险**：高阶曲面模型在目标与背景交织时易产生过拟合凹陷。
  - **对策**：排除实际可见主体、暗尘埃与微弱外缘；近似线性梯度可评估 `subsky 1`，不能仅凭一阶就认定主体受保护；若独立验证显示无显著改善或暗部越界，则安全回退并保留父源。
- **孤立大星系 (如 M81/M82, M101, M31)**：
  - 外围旋臂和星系晕往往远超可见核心。优先选择较少但可靠、覆盖合格的天空样点；依据梯度形态选择一阶、RBF 或有曲率证据支持的多项式，均须独立检查外晕。不因目标名称自动认定天空不足或固定模型。
- **行星状星云与紧凑星团 (如 M57, M13)**：
  - 利用主体外可确认的天空覆盖；按实际平面、曲率或复杂残差选择模型，不因目标紧凑就提高阶数。

## 故障定位

按 [排查参考](../troubleshooting.md) 定位新增问题；拒绝的候选不得作为修订父源。

| 故障现象 | 潜在原因 | 排查与处置对策 |
|---|---|---|
| **星云周围出现大面积黑斑/黑坑** | 样点错误落在微弱云气或暗星云内部，导致信号被过度减除 | 拒绝候选并保留父源；检查天空标签、扩大保护区并修订样点。降低阶数可作候选，不能保证消除误减。 |
| **四角亮度依然不均，暗角明显** | 真实结构、样点不足或模型不匹配，亦可能涉及上游平场 | 先检查独立天空区域；仅在证据支持时选择原子协议列出的其他模型，否则保留父源并记录限制。 |
| **减除后全图星点产生硬黑色边缘** | 背景模型可能包含亮星光晕 | 拒绝候选，核对完整采样框与星晕排除范围；从同一父源修订合同并重新验证覆盖。 |
| **背景颜色发生严重漂移** | 各颜色通道单独做高阶拟合，导致通道间基准失调 | 保持通道联动或仅拟合大尺度亮度斜坡，将色彩平衡交给 Stage 4 处理。 |

<a id="background-subtract"></a>
## background.subtract


<a id="background-subtract-适用条件"></a>
### 适用条件

只对 linear 父源执行。完整处理先完成上方必做评估；实测证据充分时可由 Agent 记录依据并跳过候选，否则真实天空控制区和样点合格时实际试跑，收益由独立验证与视觉审查决定。
- **模型选择**：按当前天空与目标保护证据选择一至四阶多项式或 RBF；一阶为近似线性梯度的推荐起点，不规定固定尝试顺序。
- **保留父源条件**：上述实测证据充分并记录跳过依据，或控制区提议与一次人工修订后仍没有可信天空，或采样及允许补救后覆盖仍不足，或实际候选无收益、被拒绝或不确定。触发新增暗部越界 0.01% 保护门时不采用候选；来源或证据错误继续阻断，不能写成无收益跳过。

<a id="background-subtract-样点协议"></a>
### 样点协议

- Siril 原生自动网格的 `-samples=20` 表示每条水平行默认 20 个样点，不是全图总数。
  本协议使用 `-existing`，直接拟合合同中已安装的样点，不重新按该默认值生成网格。
  辅助采样器未指定数量时默认 `--samples-per-line 20`：横向 20 列，纵向
  `ceil(20 × height / width)`，保留 4% 边缘留白。这是候选单元数，例如 M31 的 20×36，
  不是最终样点数。最终最多 256 点，由真实天空覆盖决定。
  `--samples` 保留“目标总数”语义，与 `--samples-per-line` 互斥；手动合同不要求规则网格。
  执行报告应分别记录采样来源、实际总数及可适用的行分布，不能把它们称为同一个“默认样本数”。
  可在下方调用中显式使用 `--samples 12`、`--samples 24` 或 `--samples 36`，按已确认天空范围减少拟合点目标数；这些是选择示例，不是必须逐级重试的顺序，也不改变采样器默认值。实际合格点数可少于目标，标准布局必须满足至少 12 点及全部覆盖要求；显式受限一阶布局最低 6 点。较少点数本身不证明更安全，也不能创造缺失的真实天空。
- 实际查看父源预览与控制区局部，确认主体保护和梯度形态；仅全幅梯度不明显不能省略候选，须满足上方实测证据条件并记录依据；
- 控制区冻结后，完整处理必须调用自动化采样工具生成哈希绑定合同与报告；NGC 6888 等弥散发射遍布画面的天区结合下方人工样点指南审查或修订。辅助工具使用
  [CLI 合同](../cli-contract.md#解释器与入口) 中已验证的 `STARUN_PYTHON`：
  ```bash
  "$STARUN_PYTHON" /abs/starun-siril/scripts/siril_auto_samples.py \
    --source "/abs/current-parent.fit" \
    --output "/abs/session/reports/030-background/background-sample-contract.json" \
    --report "/abs/session/reports/030-background/sampling-report.json" \
    --exclude-regions "/abs/session/reports/030-background/regions.json" \
    --target-type [emission_nebula|galaxy|cluster|general]
  ```
  该工具使用保持长宽比的区域中位数缩略图，先估计仅用于识别的一阶稳健趋势，分别识别恒星尖峰
  与连续天体结构，保护 RGB 任一通道中的信号。每个候选单元选择局部稳定的安全位置，不按全图
  单一亮度中心剔点；无论是否超过上限，都先覆盖天空分区，再按最大空间间距筛选，禁止最终 25×25 框重叠，结果排序固定。
- FITS/XISF 均直接读取科学像素，XISF 选 Image 0；预览仅用于实际审查，不生成可执行样点。
  内部科学数组统一为 channel/y/x、FITS 底部起算；XISF 反转 Y，浮点按声明 bounds 换算，
  无符号整数按类型满量程解释，保留负值、超范围值与非有限值，不裁剪或按实际最大值缩放。
  SirilPy 样点与 regions.v1 同为左上起算；从科学数组转换为 y_sample = height - 1 - y_raw。
  报告记录科学父源指纹、采样来源、网格、排除计数、覆盖与不足原因；各排除掩膜可重叠。
- 按固定 SirilPy 1.0.25 的默认 **25×25 像素采样框**检查完整范围；触碰连续天体结构、亮星或宽星晕、无效边或
  非有限像素时拒绝。非有限数据或来源变化不生成可执行合同。背景中性化 `--regions` 保持独立
  的默认目标总数 36 与 16×16 区域尺寸，不接受 `--samples-per-line`。
- 亦可由 Agent 手动指定样点：样点必须位于图像范围内，避开目标、恒星晕、发射结构或尘埃；
  自动结果或人工补点后均按显式布局用 `assess_sample_coverage()` 检查：标准布局至少 12 个有效点，画幅上、中、下
  三个水平分区各至少 2 点，X/Y 跨度各达到去掉 4% 留白后的有效画幅的 60%。严格路径不足时按下方
  采样补救规则补救一次，记录各路径的原因；禁止放宽主体保护，完成提议与审查仍没有可分离天空时保留父源。
- 创建 `reports/NNN-background/background-sample-contract.json`，使用
  [background sample contract Schema](../background-sample-contract.schema.json)，绑定父源绝对路径、
  SHA-256 与实际尺寸；
- 样点 ID 和坐标不可重复，坐标必须是有限数且位于图像边界内。

目标、星晕和尘埃的识别可由自动算法掩模辅助并结合 Agent 视觉确认，不另外写入机器合同。
候选执行后仍按通用 review receipt 审查父源与结果，背景样点合同不包含独立 review。

<a id="background-subtract-模型"></a>
### 模型

- `polynomial-1`：`subsky 1 -existing`，近似线性加性梯度的推荐候选；低自由度减少局部曲面拟合能力，但仍可误减目标的低频分量；
- `polynomial-2`：`subsky 2 -existing`，用于独立天空证据支持的弯曲加性背景，不限于同心对称形状；乘性渐晕应核查上游平场，不能用减曲面恢复丢失的目标响应；
- `rbf`：`subsky -rbf -existing -smooth=0.5`，用于有证据的复杂、非多项式加性背景，也可在较少可信样点且覆盖合格时选择。0.5 为平滑参数起点；大尺度平滑渐变可考虑更高平滑度，局部渐变可考虑更低平滑度，调整须说明实际残差尺度。样点纯净、覆盖及正则化决定适用性，不能要求普遍比多项式更密的样点；
- `polynomial-3` / `polynomial-4`：`subsky 3 -existing` / `subsky 4 -existing`，仅在独立天空存在对应曲率证据、样点数量足以约束模型且空间分布充分时选择。通用的至少 12 点不自动证明高阶模型可用；稀疏或受污染采样不能靠升阶解决。Siril 1.4.4 最高四阶，不生成更高阶候选。

模型按梯度形态与可信天空选择，目标形态决定保护范围；不按天体名称套模型。追加尝试必须说明前一候选的具体问题及本次可修正依据，仍以同源独立控制区和实际目标/星点审查验收。无收益且没有可修正证据时结束本阶段，不以提高阶数强求采用。命令变体的语法与参数按现有手册查询协议保存证据，科学 SSF 骨架保持下方单协议结构。

<a id="background-subtract-ssf-知识关系"></a>
### SSF 知识关系

适用性、模型和样点坐标来自当前父源、实际预览与 session 证据；本协议对应的阶段文件是 SSF 的 primary protocol
reference，提供边界和参数化骨架；冻结 Siril 1.4.4 手册提供 `pyscript/subsky/mtf` 的语法语义；
`command-policy.json` 独立决定是否可执行。Agent 生成单协议 SSF 及同 stem provenance，不把本节串成固定流水线。
逐字采用下方完整变体时可记录 manual lookup `not_needed`；改用未展开选项或遇到歧义时必须查询原文。

<a id="background-subtract-审查与回退"></a>
### 审查与回退

执行前实际查看样点覆盖图，逐框确认天空、星晕与主体保护；中部天空必须参与拟合约束。
确认 injection receipt 中的请求坐标与 Siril 实际保留坐标一致。

执行前冻结 `starun-siril.regions.v1`。标准布局至少 6 个互不重叠背景 ROI，每个至少 75×75，
上、中、下有效画幅分区各至少 2 个，中心 X/Y 跨度各覆盖去掉 4% 留白后的有效画幅的 60%。
父源哈希与尺寸必须一致。拟合的完整 25×25 框必须避开背景 ROI 及其外扩 25 像素区域；
冻结验证区域及布局之后才提议样点，不能根据候选结果重新挑选天空。受限布局仅按[专项条件](#limited-plane-layout)执行。

SSF 必须且只能有一条 `# background-validation: {"regions":"reports/<run-id>/regions.json","sha256":"…"}`。
区域、样点合同与 injection receipt 必须位于当前 SSF run 的同一报告目录。目录不一致会报告
`directories differ` 或 `directory must match the SSF run ID`，不是文件已存在；将证据复制到新 run
目录并重新绑定哈希，不能覆盖旧 receipt。运行期间再次核对区域和样点合同哈希。

新会话冻结 `background=heldout_review_gate_v5`；历史 v4 的科学读取和原收益判定保持。S3 支持现有解码集内的 mono/RGB FITS/XISF 父源；候选必须保存为 float32 FITS。
其他格式阻止背景候选，不能回退到 JPEG。每个 ROI 使用完整互不重叠 25×25 块，区域值为块中位数的
中位数，空间跨度为跨区域 `p90−p10`。RGB 亮度为逐像素 Rec709 加权值；色差逐像素计算 `R−G`、`B−G`，
之后才求块中位数，禁止以区域通道 median 的加权或差值代替。原生通道、常数偏移及偏移空间跨度继续报告。
原有全像素 ROI 统计是独立诊断，不作为此估计器。

成对父源/候选在同一 ROI、所有维度使用相同抽样索引：NumPy PCG64、seed=0、2,048 次。
改善门槛为 `max(3 × std(parent_span − candidate_span), 1e-6)` 归一化科学单位。
这是工程启发式，不是校准后的物理置信保证。v5 的亮度或任一色差只要存在数值正空间改善，就进入 `review_required`；未超过原门槛时记录 `low_significance_benefit`，保留原 improved/worsened、bootstrap 和全部数值。Mono 只用亮度。报告区分数值可送审的 benefit_dimensions 与各维度的统计 improved 标志，送审不等于采用。

恒等、全幅逐通道差值在两 float32 ULP 内为常数的纯 DC、或没有正空间改善时仍 skip。任一维度超过门槛恶化保留告警；Agent 必须解释小收益和其他维度代价，结合独立天空及同显示局部对照确认可复核收益，且弱云气、反射区、外缘和全部适用门通过后才能接受。无法确认收益或主体退化时保留父源，不要求每个通道都改善。旧 v4 及此前策略继续要求超过原统计门槛，不能用 v5 重新解释旧 skip。

暗部保护使用全画幅成对像素：逐通道统计 `parent > 0 and candidate <= 0`，新增越界比例达到
`0.0001`（0.01%）时阻断。其他位置恢复不能抵消新增越界。父源/候选已有非正值及高光端点计数分别
保留，不追溯否决原图已有缺陷。此边界保护是工程规则，不宣称证明了物理截断；全图计数仍不能排除局部损伤。

运行时绑定 `reports/<run-id>/background-validation.json`，采用 `starun-siril.background-validation.v2`。
`status=passed|failed|uncertain` 表示技术验收；`decision=review_required|skip|blocked` 表示候选处置，另有
`benefit_dimensions` 与 `warnings`。passed 的 run 执行成功，skip 产物只供诊断；failed/uncertain
使 run failed 并保留现场。skip/blocked 不能成为父源或进入 selected lineage，手写 accept/finalize 不能覆盖。
历史测量策略见末尾兼容说明。

review 必须实际打开并绑定同一显式 MTF 的父源/候选 JPEG 和本 run 背景报告。记录数字告警、保护区域
具体观察及采用理由。实际检查外盘、星系晕及伴星系，确认天空连续性收益且无坑洞、误减、条纹、颜色关系
破坏或微弱结构丢失；这些确认的损害仍 reject，观察不确定则保留父源。训练区与控制区若都混入微弱目标，更平的背景仍不能证明目标未被误减。证据错误继续阻断采用。
点数足够、技术 passed 和原生命令成功均不能替代五项实际视觉审查；不自动写 accept，不增加颜色豁免。

<a id="background-subtract-v3-来源规划采样补救与精度"></a>
### 来源、采样补救与科学精度

先执行 input.inspect 并实际查看来源。完整处理必须使用辅助采样器 `--validation-regions --source /abs/master.fit --output /abs/proposals.json --report /abs/proposal-report.json` 提议独立控制区；传入当前已接受科学父源的真实绝对路径，FITS/XISF 均可。
新模式固定 75×75，在上中下与左右六个搜索区各最多提出三个互不重叠区域；按结构占比、紧凑星点污染和 RGB 块中位数稳定性排序，不挑绝对最暗值。
输出 `starun-siril.background-region-proposals.v1`，不能直接作为 `regions.v1` 执行。Agent 查看来源局部图，选择或修订六个合格天空区，将选择依据写入 provenance 后冻结。
控制区不足时允许一次人工修订；采样人工修订同样最多一次，不根据候选结果移动控制区。全图偏色本身不证明天空不存在；完整处理不能在这一步之前仅凭预览写下跳过决定。

缩略图仅搜索，完整采样框按原生像素坐标精确检查。`regions.v1` 的 core/faint/stars 矩形也硬排除。
严格路径覆盖合格时不启用补救；只有严格路径不足且提供有效 `--exclude-regions` 的科学 FITS/XISF 25×25 背景采样，才执行一次 `sparse_compact_star_v1`。背景中性化 --regions 不启用。
补救保留原有 RGB 联合连续结构与暗云保护。在 45×45 原生上下文用 9×9 局部中位数检查：任一通道正异常 >20×pixel_noise 或科学值 >=1 的像素及外扩 6 像素继续硬排除；>5×pixel_noise 的普通紧凑峰外扩 2 像素。
完整 25×25 框的联合紧凑掩膜比例不得 >10%，每通道完整/诊断排星中位数差不得 >max(0.15×pixel_noise,1e-6)。阈值是固定工程启发式，不是物理置信保证，不按目标点数调整。
报告分别记录严格和补救覆盖及逐框污染；Python 不把排星统计注入 Siril、不写科学像素。补救仍不足时不产生可执行合同。

科学分支恰好执行一次 fmul 1，位置必须紧跟父源 load、且在注入前，禁止其他倍率。适配器只读 get_image()，要求 float32/-32、几何通道有限性保持，归一化值误差 <=2 float32 ULP，0/1 端点保持。
精度证据绑定 injection receipt 与 background-validation.v2；科学保存须 BITPIX=-32。set32bits 日志本身不能替代此证据。不能在拟合后才转换格式掩盖表示损失。
背景报告继续使用 `starun-siril.background-validation.v2`；报告 policy 使用会话冻结的 `session.execution_policy.background`。旧记录按原 policy、公式与判定回放，不用文档 guidance 替换冻结值。


经审计入口为 `siril_background_samples_scientific.py`，旧桥接保持原字节。injection receipt 绑定科学 Image 0 选择、声明单位、来源行方向与 canonical FITS 底部起算行。安装样点前，原生 float32 像素须在两个 ULP 内一致且 0/1 端点精确保留。解码、bounds、方向、哈希或几何失败阻断处理，不能当作无收益跳过；不允许其他桥接、隐式转换或失败回退。

公开 metrics ROI 仍只接受 FITS；Stage 4 native neutral 内部读取 FITS/XISF。Agent 仅采用同源且实际审查接受的背景候选。

<a id="manual-samples-for-field-filling-diffuse-emission"></a>
## 满幅弥散发射的人工样点

NGC 6888 等天区的暗角也可能含真实微弱发射。完整处理仍须先提议、实测并局部审查独立天空区，不能因可见气壳较小就自动认定全画幅网格安全，也不能仅因全幅没有显著梯度跳过评估。只有满足上方实测证据条件才可记录依据并跳过候选，否则控制区与样点合格时实际试跑；可信天空不足或试跑无收益时保留父源。

1. 在来源绑定的 `regions.v1` 中用 `core/faint` 矩形保护壳层及延伸发射，暗尘埃和星晕用 `faint/stars` 补充。以人工确认的壳层框 `[x0,y0,x1,y1]` 为中心，长宽各扩大至 1.5 倍，边界向外取整并裁到画幅。这是总保护宽度/直径，不是从每条边再向外延伸 1.5 个直径。按实际弥散发射继续扩大或追加矩形，范围之外不自动是天空；不按天体名称自动画框。
2. 用左上起算来源坐标人工填写 `fit_samples`。每角 3–5 点只是候选布局，不是数量门或纯天空证明；避开无效边，逐一检查完整固定 25×25 框中的暗星、亮星、星晕与发射。Siril 网格容差是亮度偏差因子（命令以 MAD 为单位），不是 15–20 像素框尺寸；桥接框保持 25×25。
3. 保留标准布局至少 12 个有效点，上、中、下各至少 2 点及既有 X/Y 跨度；受限一阶按其独立条件执行。中部侧边也须有保护区之外的已确认天空。标准布局拟合前冻结六个独立至少 75×75 的背景 ROI，保持同一覆盖要求及外扩 25 像素隔离；仅四角不能约束中部。提议与一次人工修订后仍没有可信中部天空或独立控制区时跳过，保留父源；不能缩小星云保护或把发射改标为背景。
4. 需要试跑时沿用桥接清空旧样点、仅安装声明坐标并核对实际保留位置。近似平面加性梯度用 `subsky 1 -existing`；独立天空支持曲率时可用 `subsky 2 -existing`。RBF 或三/四阶沿用上方模型选择条件，其他天区同样按实际证据选择，不按名称禁止或强制某种模型。一般二阶曲面不必中心对称，也可能吸收真实大尺度发射；减曲面不修复乘性暗角，应核查上游平场。
5. 试跑后对照固定显示传递的父源/候选预览、科学报告和微弱保护结构。更平或更暗不证明信号保留；收益、新增暗部越界及五项视觉门不变。新增坑洞或发射丢失 reject，证据不确定保留父源，不自动 accept。

### 完整样框与保护区

`background_sampling=protected_regions_v1` 约束采样隔离，不替代会话冻结的 `background` 收益与端点判定。自动和人工拟合完整样框、完整背景验证 ROI 均不得与任何 `core/faint/stars` 保护矩形相交；错误指出样点/ROI 与保护区 ID。该标签绑定静态处理元数据、处理后报告与 receipt 回放；regions、样点 schema、CLI 与科学容差不变。

没有新采样标签的历史记录沿用冻结校验与精确知识指纹，不获得新增执行权限。旧测量与桥接证据只用于回放/finalize，不重算或重写旧失败结果。
